- **能力变化与用途**：
  - `build-mcp-server`：入口 skill，询问连接对象、用户范围、action surface、交互需求、上游认证，再选择部署模型和工具设计模式。

- **行动建议**：新项目从 `build-mcp-server` 触发发现阶段；只在需要用户界面时接 `build-mcp-app`；只在必须访问本机时接 `build-mcpb`。上线前把 tool descriptions 当不可信输入处理，保留用户授权和审计日志。

## 今天值得深入研究的 1 个主题

**Agent Skills 会不会成为 2026 下半年 AI 工具的“插件标准层”？**

今天的信号很集中：GitHub Trending 上 `mattpocock/skills`、`obra/superpowers`、`mukul975/Anthropic-Cybersecurity-Skills`、`cursor/plugins` 都在增长；MCP 官方 Build with Agent Skills 也把 `mcp-server-dev` 的 skill 作为 MCP server 开发入口。值得深入研究三件事：第一，skill 与 MCP tool 的边界，哪些是“过程知识”，哪些是“可执行能力”；第二，skill 安全模型，如何避免恶意 `SKILL.md` 引导 agent 读取 secrets 或执行危险命令；第三，团队级分发机制，如何让优秀流程跨 Codex、Claude Code、Cursor、OpenCode 等客户端复用。

建议产出：挑一个内部高频流程，例如“PR 评论处理”“线上事故复盘”“竞品页面采集与结构化摘要”，写成可跨 agent 使用的 `SKILL.md`，并补充权限要求、失败处理、验证步骤和禁用动作。
