## MCP / Agent Skills 更新

- **官方 MCP 当前规范基线仍是 2026-07-28。** 本次打开 [MCP Specification](https://modelcontextprotocol.io/specification) 会重定向到 `/specification/2026-07-28`。该版本强调 JSON-RPC、stateless requests、per-request capability negotiation、Resources / Prompts / Tools，以及 Tasks、Skills over MCP、MCP Apps 等 opt-in 扩展。

- **最新可见变化：2026-09-08，Skills over MCP stable spec 页缓存语义调整。** `modelcontextprotocol/ext-skills` 决策日志新增“Stable spec page”条目，要求 `ListSkillsResult` 扩展 `PaginatedResult` 和 `CacheableResult`，`GetSkillResult` 也扩展 `CacheableResult`，也就是 `skills/list` 和 `skills/get` 都要携带 `ttlMs` 和 `cacheScope`。能力变化：客户端可以缓存 skill listing / single skill metadata，并用 TTL 与 scope 控制新鲜度和共享边界。迁移影响：skill server 不能只返回清单字段，要补缓存字段；client 也要尊重缓存失效。适合谁试用：正在做 MCP skill registry、企业 skill catalog、跨工具 skill 安装的团队。来源：[ext-skills decisions](https://github.com/modelcontextprotocol/ext-skills/blob/main/docs/decisions.md)。

- **同一条 2026-09-08 决策还明确 Resources 能力依赖。** 决策保留“声明 skills 扩展的 server 必须也声明 resources 能力”的要求，但表述为 base Resources 规范的结果，而不是孤立新规则。能力变化：skills 不只是 metadata，支持文件和 `SKILL.md` 要通过 resource read 读取并验证。迁移影响：只暴露 `skills/list` 但不暴露 `resources/read` 的实现会不完整。行动建议：把 `resources/read`、per-file digest、缓存字段一起做掉，少走弯路。

- **SEP-2640 v1 方向继续保持：`skills/list` + `skills/get` + per-file digests + no archives。** 7 月 15-16 日决策仍是主干：`skills/get(uri)` 用于拿单个 skill entry；archive 分发被移除；`resources/directory/read` 变为可选；skill URI scheme 不再有特权；同名 skill 要按 URI 和 origin 消歧。能力变化：更少传输形态，更好做内容绑定和安全审查。迁移影响：旧的 `skill://index.json` 或 archive 方案不要继续扩展。

- **OpenAI Agent Skills 基线：Skills 页面最后更新仍为 2026-09-04。** OpenAI Academy Skills 页面显示 2026-02-25 发布、2026-09-04 更新，核心仍是“可共享、易构建、跨产品/表面工作”的 SKILL.md + 支持资源模式。Agents API 示例中也出现 `capability_directories: ["/workspace/capabilities/skills"]`，说明 skills 已进入托管 agent 环境配置。来源：[OpenAI Academy Skills](https://academy.openai.com/public/clubs/work-users-ynjqu/resources/skills)、[OpenAI Agents API](https://openai.com/index/introducing-the-agents-api/)。

- **结论：未发现比 2026-07-28 更新的 MCP 主规范版本，但发现 2026-09-08 Skills over MCP 决策更新。** 可复用做法：skill 包保持小而清楚；把触发条件、权限假设、输入输出、支持文件写明；分发时准备 `skills/list`、`skills/get`、`resources/read`、per-file digest、`ttlMs` / `cacheScope`。
