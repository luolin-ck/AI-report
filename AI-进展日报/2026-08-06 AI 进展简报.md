<h2>分领域进展</h2>

<h3>设计生成</h3>
<ul>
<li>Figma Code Connect in MCP 是今天最重要的设计到代码信号。它证明 Agent 需要“生产组件上下文”，否则容易从视觉节点手写假组件，造成样式相似但交互、可维护性和设计系统一致性失败。对团队的直接动作是补齐 design system 的 Code Connect 覆盖率，并把 Figma MCP 输出作为工程上下文，而不是只当视觉参考。</li>
<li>Figma News 页面还显示 Figma Make 的 properties panel、annotations、GPT-5.6 in Figma Make 等近期条目。今天没有新的独立 Claude Design / OpenDesign 官方发布可核验，但 YouTube 侧 Claude Design motion graphics 教程仍在传播，说明“用 AI 生成可动效原型”是近期创作者关注点。</li>
<li>Product Hunt 的 AI/AI Agents 分类近期也把 AI Designer、AI Workflow Automation、OpenClaw、voice-first Mac agent、AI creative studio 等放在同一增长带。热度不等于成熟度，值得试的是能把设计、代码、发布或运营动作打通的工具，不是只生成图片的单点工具。</li>
</ul>

<h3>数据采集 / RAG</h3>
<ul>
<li>Firecrawl 的最新官方文章把 PDF summarizer 拆成 parse、OCR、table preservation、API/MCP/CLI、schema JSON 几层，重点已经不是“摘要”而是“给 Agent 和 RAG 管线稳定供上下文”。如果业务文档里有财报、合同、扫描件，先做文档解析评测，再谈 RAG 检索效果。</li>
<li><a href="https://github.com/firecrawl/pdf-inspector">firecrawl/pdf-inspector</a> 今日在 GitHub Trending 可见 11,325 stars、1,583 stars today。它的定位是 Rust PDF inspection/classification/text extraction，可用于判断页面是扫描件还是文本型 PDF，从而减少不必要 OCR 和 GPU 成本。</li>
<li>数据采集工具正在向“低摩擦 Agent 工具”靠拢：Firecrawl MCP/CLI、Product Hunt 上的 AI Browser/Webhound、Cloudflare Gatekeeper/MCP Portal 都在解决同一件事，即让 Agent 在可审计边界里拿到可用数据。</li>
</ul>

<h3>Agent 工作流</h3>
<ul>
<li>Cloudflare OS 是今天最值得拆解的 Agent 工作流案例：它把工作空间、技能文件、可分享 app、Gatekeeper、MCP Server Portal、AI Gateway、动态 Worker、Durable Object/SQLite 串成一个企业平台。关键不是“又一个聊天界面”，而是用户权限继承、凭据隔离、外网默认关闭、模型成本治理和可审计输出。</li>
<li>Cloudflare Agent Access Model 明确提出“不要信任一次 run，要对每个 action 重新授权”。这与近期 OpenAI/Anthropic/AISI 安全事件形成直接呼应：prompt 只能表达意图，不能作为边界。</li>
<li>HN Algolia 最近 48 小时公开抓取中，相关条目包括 “AI agents that inherit the user's permissions, not API keys”、Ask HN “How to turn Claude Code into an effective software engineer”、Show HN “Mirafold - Generative UI for Claude Code, Codex, and Gemini CLI”。互动数很低，多数只有 0-1 条评论，属于早期开发者讨论，不是大众爆点。</li>
</ul>

<h3>热门应用</h3>
<ul>
<li><strong>Cloudflare OS：</strong>适合企业内希望让员工自建 Agent/app，但又不能分发 API keys 的团队。值得试，但部署价值取决于你是否愿意建设 Gatekeeper 和内部资源模型。</li>
<li><strong>CrocoBuilder + Claude Code MCP：</strong>适合 WordPress/网站设计团队观察“页面构建器 + Claude Code + MCP”的产品化方向。视频含 paid promotion，应当把它当案例而不是中立评测。</li>
<li><strong>Product Hunt AI Agents recent launches：</strong>Phantom、Conduit、Webhound、FlowTask、Prefactor、LapuAi 等近期产品共同指向“更窄场景 + 更深集成”。泛泛称自己是 AI Agent 已经不够，能进真实工作流、带审批/评测/记忆的产品更值得关注。</li>
</ul>

<section>
<h2>今天值得深入研究的 1 个主题</h2>

<blockquote>
<p><strong>Agent 权限与上下文治理成为产品能力，而不是安全附录。</strong></p>
</blockquote>

<p>Cloudflare OS、Agent Access Model、Figma Code Connect、Firecrawl MCP/PDF 解析、OpenAI/Anthropic/AISI 安全事件都指向同一个结论：下一阶段的 Agent 竞争，不只看模型能力，而看“它在什么上下文里行动、凭什么权限行动、读过什么数据、输出给谁、每一步能否审计和撤销”。建议拆成四个检查项：任务级短期凭据、工具/网络双层 enforcement、已读资源 observation log、设计/代码/文档上下文的结构化注入。</p>
</section>
