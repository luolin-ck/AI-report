## 分领域进展

### 设计生成

Figma 的官方路线仍然是“Canvas + Code + MCP”：Figma 2026 年发布的 [Figma Design Agent](https://www.figma.com/blog/the-figma-agent-is-here/)、[Figma MCP Server 文档](https://developers.figma.com/docs/figma-mcp-server/) 和 [Code Connect integration](https://developers.figma.com/docs/figma-mcp-server/code-connect-integration/) 都强调结构化设计上下文、组件/token/变量和代码组件映射，而不是只靠截图。今天的新增信号是社区产品围绕这一层补齐：Lokuma 把“设计品味/设计 skill”卖给编码 Agent，Agentation 把设计反馈变成 Agent 能执行的 Markdown/MCP 上下文。

可行动建议：设计团队可以先把按钮、表单、卡片、导航、图表等核心组件做 Code Connect 或等价映射，再让 Agent 生成 UI；没有组件映射时，AI 设计容易回到“看起来像设计、实际不可维护”的状态。

### 数据采集 / RAG

Firecrawl 的近期主线是 `/search`、Research Index、`/parse` 和 PDF 智能解析。[Firecrawl changelog](https://www.firecrawl.dev/changelog) 显示 2026-07-22 的 `/search` 返回最能回答查询的摘录，强调 SimpleQA 94.7% 与少用 10x tokens；GitHub 上 [firecrawl/pdf-inspector](https://github.com/firecrawl/pdf-inspector) 则主打 PDF inspection、classification、text extraction 和扫描件/文本型 PDF 路由。

Neon 与 Castform 的 [agentic search 文章](https://neon.com/blog/how-castform-neon-beats-frontier-models-on-price-and-efficiency) 提出另一个方向：把企业已有 Postgres/知识库变成强化学习后训练环境，让小模型学习多轮检索工具调用，目标是在特定检索任务上降低前沿模型成本。适合关注 RAG 成本的团队复盘，但需要看实际数据集、reward 设计和离线评估是否能迁移到自家场景。

### Agent 工作流

Meta Muse Code 的重点不是单一模型，而是运行时：异步 background agents、可回放事件日志、长期任务恢复、默认 `/plan`、`/grill`、`/goal` skills，以及 1,000+ tool calls 的 kernel 优化案例。Prime Intellect 的 [Prime Agent](https://www.primeintellect.ai/blog/prime-agent) 也把方向压在 harness 上，提出 Recursive Language Model、Continual Harness、persistent IPython kernel、sub-agent CRUD 和 agent-to-agent messaging。

结论：Agent 工作流的下一轮竞争会发生在“谁能让任务跑更久、上下文更少丢、子 Agent 更可控、失败后可恢复”。建议在试用任何新编码 Agent 时，记录它的事件日志、权限请求、失败恢复、上下文压缩和测试验证行为，不要只看一次 demo 是否跑通。

## 今天值得深入研究的 1 个主题

**主题：Agent 权限、出站访问和数据外泄的确定性治理。**

为什么选它：ScaleX 的人类审批数据、PromptArmor 的 Rovo 外泄、Cloudflare OS 的 sandbox/gadget 权限模型、Meta Muse Code 的持久子 Agent，都指向同一个问题：Agent 越能做事，越不能只靠用户点击批准。

建议研究清单：

1. 为本地/云端 Agent 分离 4 类能力：文件读写、网络出站、MCP/连接器、命令执行。
2. 对 URL fetch 做确定性策略：用户显式提供、可信搜索工具返回、域名白名单、禁止 Agent 拼接私有数据到 URL。
3. 把 secrets 从工作目录和 shell profile 中剥离，默认不给 Agent 读取 home 目录。
4. 用独立 VM/sandbox 跑 coding Agent，保留可审计事件日志。
5. 在 CI 里增加 Agent 生成代码的安全审查，尤其是 package scripts、postinstall、curl、动态下载和权限变更。
