1. 4. Firecrawl 官方继续强化 PDF/RAG 数据入口叙事，强调 `/parse`、OCR、表格保留、MCP、CLI 和 schema JSON。来源：[Firecrawl PDF summarizer tools](https://www.firecrawl.dev/blog/best-ai-pdf-summarizer-tools)。影响：RAG 数据采集从网页抓取扩展到 PDF/Office 文档解析，文档结构保真比“摘要好不好看”更关键。行动建议：做知识库前先把 PDF 页面类型、OCR 路由、表格抽取和引用回溯链路跑通。

## 分领域进展

### 设计生成

- Figma Code Connect in MCP 是今天最重要的设计到代码信号。它证明 Agent 需要“生产组件上下文”，否则容易从视觉节点手写假组件，造成样式相似但交互、可维护性和设计系统一致性失败。对团队的直接动作是补齐 design system 的 Code Connect 覆盖率，并把 Figma MCP 输出作为工程上下文，而不是只当视觉参考。
- Figma News 页面还显示 Figma Make 的 properties panel、annotations、GPT-5.6 in Figma Make 等近期条目。今天没有新的独立 Claude Design / OpenDesign 官方发布可核验，但 YouTube 侧 Claude Design motion graphics 教程仍在传播，说明“用 AI 生成可动效原型”是近期创作者关注点。
- Product Hunt 的 AI/AI Agents 分类近期也把 AI Designer、AI Workflow Automation、OpenClaw、voice-first Mac agent、AI creative studio 等放在同一增长带。热度不等于成熟度，值得试的是能把设计、代码、发布或运营动作打通的工具，不是只生成图片的单点工具。

### 数据采集 / RAG

- Firecrawl 的最新官方文章把 PDF summarizer 拆成 parse、OCR、table preservation、API/MCP/CLI、schema JSON 几层，重点已经不是“摘要”而是“给 Agent 和 RAG 管线稳定供上下文”。如果业务文档里有财报、合同、扫描件，先做文档解析评测，再谈 RAG 检索效果。
- `firecrawl/pdf-inspector` 今日在 GitHub Trending 可见 11,325 stars、1,583 stars today。它的定位是 Rust PDF inspection/classification/text extraction，可用于判断页面是扫描件还是文本型 PDF，从而减少不必要 OCR 和 GPU 成本。
- 数据采集工具正在向“低摩擦 Agent 工具”靠拢：Firecrawl MCP/CLI、Product Hunt 上的 AI Browser/Webhound、Cloudflare Gatekeeper/MCP Portal 都在解决同一件事，即让 Agent 在可审计边界里拿到可用数据。

### Agent 工作流

- Cloudflare OS 是今天最值得拆解的 Agent 工作流案例：它把工作空间、技能文件、可分享 app、Gatekeeper、MCP Server Portal、AI Gateway、动态 Worker、Durable Object/SQLite 串成一个企业平台。关键不是“又一个聊天界面”，而是用户权限继承、凭据隔离、外网默认关闭、模型成本治理和可审计输出。
- Cloudflare Agent Access Model 明确提出“不要信任一次 run，要对每个 action 重新授权”。这与近期 OpenAI/Anthropic/AISI 安全事件形成直接呼应：prompt 只能表达意图，不能作为边界。
- HN Algolia 最近 48 小时公开抓取中，相关条目包括 “AI agents that inherit the user's permissions, not API keys”、Ask HN “How to turn Claude Code into an effective software engineer”、Show HN “Mirafold - Generative UI for Claude Code, Codex, and Gemini CLI”。互动数很低，多数只有 0-1 条评论，属于早期开发者讨论，不是大众爆点。

## 今天值得深入研究的 1 个主题

**Agent 权限与上下文治理成为产品能力，而不是安全附录。** Cloudflare OS、Agent Access Model、Figma Code Connect、Firecrawl MCP/PDF 解析、OpenAI/Anthropic/AISI 安全事件都指向同一个结论：下一阶段的 Agent 竞争，不只看模型能力，而看“它在什么上下文里行动、凭什么权限行动、读过什么数据、输出给谁、每一步能否审计和撤销”。建议拆成四个检查项：任务级短期凭据、工具/网络双层 enforcement、已读资源 observation log、设计/代码/文档上下文的结构化注入。
