## 今日最值得关注

1. **GPT-5.6 和 ChatGPT Work 把“工作代理”推到主战场。** The Verge 与 Axios 报道 OpenAI 在 7 月 9 日发布 GPT-5.6 与 ChatGPT Work，面向文档、表格、Web app、CRM/Gmail/Slack 等多步工作流。影响：OpenAI 正把 Codex 经验扩到泛办公场景。行动：先拿一个真实跨工具流程做评测，而不是只跑问答基准。来源：https://www.theverge.com/ai-artificial-intelligence/963464/openai-gpt-5-6-codex-chatgpt-work
2. **Claude Cowork 移动端/网页化，验证“后台代理”不是开发者专属。** Wired、The Verge 与 TechRadar 均报道 Cowork 可在手机和 Web 启动/监控任务，云端会话在电脑关闭时继续运行。影响：Agent 从 CLI/桌面走向随身任务队列。行动：适合测试邮件整理、会议纪要、表格核对等低风险后台任务。来源：https://www.wired.com/story/shut-those-laptops-anthropic-puts-its-claude-cowork-agent-on-your-phone
3. **Firecrawl web-scale `/monitor` 值得 RAG/抓取团队关注。** Firecrawl 7 月 1 日发布全网级 monitor：用查询词、时间窗和目标描述持续发现新页面，并通过 webhook/email 通知代理。影响：从“定时爬已知 URL”升级为“持续发现未知变化”。行动：可用于竞品、法规、论文和产品发布监控。来源：https://www.firecrawl.dev/blog/web-monitoring-launch
4. **Figma 的 AI motion/shader/Code Layers 仍在发酵。** Config 2026 后，Figma 官方 YouTube 教程和设计社区继续传播 AI Motion、shader effects、Weave workflows 与 Code Layers。影响：设计生成正在从静态 UI 走向动效、视觉处理和代码协作。行动：设计团队应把 prompt 生成结果纳入设计系统评审，而不是直接交付。来源：https://www.theverge.com/tech/955831/figma-code-design-tools-config-2026-announcements
5. **AI coding agent 安全成为本周硬主题。** ITPro 报道 Wiz 披露 GhostApproval，涉及 Amazon Q Developer、Claude Code、Cursor、Windsurf、Google Antigravity 等工具的 symlink/沙箱逃逸风险。影响：代理写盘、审批和符号链接处理成为新攻击面。行动：给 AI agent 加最小权限、隔离工作树、危险命令 hook 和补丁版本检查。来源：https://www.itpro.com/security/flaws-in-some-of-the-most-popular-ai-coding-tools-left-developers-wide-open-to-attack
6. **GitHub 热榜显示“代理周边基础设施”继续吸星。** Vibe-Trading、Claude cookbooks、destructive_command_guard、awesome-llm-apps、claude-code-templates 均进入官方 daily Trending 的 AI 相关筛选。影响：市场不只追模型，也追可运行工作流、安全护栏和模板资产。行动：优先试能接入现有工作流的项目。

## 分领域进展

### 设计生成

- **Figma AI motion/shaders/Code Layers：** 近期传播点不是“又一个生成 UI”，而是把 AI 放进设计画布、动效时间线、shader 视觉效果和代码同步链路。The Verge 报道 Code Layers 可让团队在 Figma 画布中与代码交互，AI motion 可通过聊天生成动画并进入时间线调整，shader effects 基于 WebGPU。适合：品牌动效、产品原型、设计系统演示；不适合：无需人工审美校准的最终交付。
- **Claude Design/OpenDesign 类工具：** 近期没有新的官方大版本，但 Claude Design 的“提示生成原型/物料 + 可交给 Claude Code 实现”路径仍是判断同类产品的标尺。OpenDesign/设计到代码工具应重点比较三点：是否读取真实设计 metadata，是否支持响应式与组件约束，是否能回写到代码仓库。

### 数据采集/RAG

- **Firecrawl web-scale `/monitor`：** 新能力将监控对象从页面/站点扩展到全网搜索结果，支持 `searchWindow`、去重、目标相关性判断和 webhook。对 RAG 来说，它更像“增量发现层”，可减少每天全量重抓。来源：https://www.firecrawl.dev/blog/web-monitoring-launch
- **Firecrawl Research Index：** 6 月 17 日发布，覆盖 300 万+ arXiv 论文及相关 GitHub artifacts，并声称在 arXivQA 上召回率 53.3%，高于下一家 45.4%。适合做 AI/ML 研究代理的文献入口，但仍需自建引用核验。来源：https://www.firecrawl.dev/blog/research-index-launch
- **抓取治理：** canary token 论文显示，站点可通过给不同爬虫返回唯一 token，再观察 LLM 输出来推断哪些爬虫进入了哪些模型训练/检索链路。行动：内容方可试验可追踪内容水印；抓取方应明确 User-Agent、用途与退出机制。来源：https://arxiv.org/abs/2605.13706

### Agent 工作流

- **OpenAI ChatGPT Work vs Claude Cowork：** 两条路线都在把 agent 从“开发工具”推向“工作入口”。OpenAI 强调 ChatGPT/Codex 合流，Claude 强调移动端与云端后台执行。实际评估应看：能否持续运行、遇到权限时如何请求确认、是否能留下可审计日志。
- **Microsoft CLI agent 研究：** arXiv 论文跟踪 Microsoft 早期 2026 年 Claude Code 与 Copilot CLI rollout，发现采用者合并 PR 数约提升 24%，但作者也说明 merged PR 不是业务价值本身。行动：企业 rollout 应跟踪“同伴可见使用 + 留存 + 质量回归”，不要只按 token 消耗判断。来源：https://arxiv.org/abs/2607.01418
- **安全护栏：** `destructive_command_guard` 登上 GitHub daily Trending，说明开发者开始给 Claude Code/Codex/Gemini/Cursor 等代理加执行前拦截。适合所有允许 agent 跑 shell 的团队先试。

## 今天值得深入研究的 1 个主题

**把 Agent 工作流产品化时，如何设计“持续运行 + 可审计 + 可撤销”的任务系统。** ChatGPT Work、Claude Cowork、Firecrawl monitor 和 GitHub 上的 agent 安全工具都在围绕同一问题：代理不再只是生成文本，而是在后台运行、读写文件、调用外部系统并等待人类确认。建议拆成四层研究：任务队列与状态机、权限与审批、结果可追溯日志、失败/回滚机制。最适合用一个真实场景验证：每日竞品/论文/社媒监控到草稿输出。
