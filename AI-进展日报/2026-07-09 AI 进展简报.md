## 今日最值得关注

1. **OpenAI 把实时语音推到更接近“可打断、可看图、可持续对话”的产品形态。** 来源：[GPT-Live 官方发布](https://openai.com/index/introducing-gpt-live/)、[Realtime API 2.1 社区公告](https://community.openai.com/t/new-realtime-models-on-the-api-gpt-realtime-2-1-and-gpt-realtime-2-1-mini/1385896)。影响：语音助手从“问答入口”变成应用交互层。行动：做客服、陪练、销售、教育产品的团队应优先评估低延迟语音链路。
2. **Figma 的 AI 方向继续从单点生图转向“Design Agent + 上下文 + skills”。** 来源：[Figma Design Agent 文章](https://www.figma.com/blog/agent-custom-tools-context-skills/)、[Figma release notes](https://www.figma.com/release-notes/)。影响：设计生成工具的竞争点变成可复用工作流和团队上下文。行动：关注设计规范、组件库、品牌资产如何被 agent 调用。
3. **OpenDesign 等开源设计生成项目开始对标 Claude Design。** 来源：[OpenDesign releases](https://github.com/nexu-io/open-design/releases)。影响：本地优先、BYOK、可导出 HTML/PDF/PPTX/MP4 的设计代理会吸引重视数据控制的团队。行动：适合用来做内部原型和销售材料，不宜直接替代成熟设计系统。
4. **RAG/抓取方向的主题仍是“给 agent 稳定网页上下文”。** 来源：[Firecrawl AI agents 文章](https://www.firecrawl.dev/blog/ai-agents)、[Context.dev 2026 crawler API 对比](https://www.context.dev/blog/website-crawler-api-comparison-for-ai-agents-2026)。影响：抓取、清洗、结构化输出、MCP 接入正在合并成一类基础设施。行动：为 RAG 项目选型时，把 JS 渲染、反爬、Markdown/JSON 输出、成本和 MCP 支持一起比较。
5. **面向 agent 的 Git/代码基础设施升温。** 来源：[Entire Git network 媒体报道](https://thenextweb.com/news/entire-distributed-git-network-agents)、[HN 讨论](https://news.ycombinator.com/item?id=48833019)。影响：AI 编码代理带来的 clone、索引、上下文同步压力正在催生新 infra。行动：大仓库团队应监控 agent 造成的代码托管、CI 和索引成本。
6. **GitHub 日榜前列被 agent skills、Office 自动化、视频理解等工具占据。** 来源：[GitHub Trending daily](https://github.com/trending?since=daily)。影响：开发者正在寻找让 agent 进入真实文件、真实流程的桥梁。行动：优先试用能嵌入现有 CLI/IDE 的小工具，而不是只看 demo。
7. **Anthropic 继续把 Claude Code 推向政府安全审查和模型可解释性。** 来源：[Alberta cybersecurity](https://www.anthropic.com/news/alberta-government-claude-cybersecurity)、[global workspace research](https://www.anthropic.com/research/global-workspace)。影响：企业采购会更关注审计、漏洞扫描、内部机制解释。行动：安全团队可关注“AI 代码审查 + 人工复核”的落地边界。

## 分领域进展

### 设计生成

- Figma 的重点是 Design Agent、custom tools、context、skills，以及 AI Image Edits 的并行编辑能力；这意味着设计生成不再只是生成画面，而是让 agent 理解团队规范、素材和交付链路。
- OpenDesign 的定位是开源 Claude Design 替代品，支持多种 coding agent 和 CLI，适合原型、landing page、dashboard、slide、图片和视频导出场景。
- 值得跟踪的判断：设计工具下一阶段的壁垒不是“能不能出图”，而是能否把设计规范、代码约束、品牌资产和业务素材沉淀成可执行技能。

### 数据采集/RAG

- Firecrawl 近期内容继续强调 agent 缺少可靠实时网页上下文的问题，方向是 search、scrape、extract、crawl 与 MCP 的组合。
- Context.dev 的 crawler API 对比把结构化输出、MCP、JS 渲染、定价和部署复杂度列为 AI agent 选型关键项。
- GitHub 日榜中的 [Graphify](https://github.com/Graphify-Labs/graphify) 把代码、SQL、文档、图片、视频转成可查询知识图谱，说明“RAG 数据层”正在从网页扩展到整个工作目录。

### Agent 工作流

- [OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)、[agent-skills](https://github.com/addyosmani/agent-skills)、[superpowers](https://github.com/obra/superpowers) 的增长说明：让 agent 读写真实办公文件、复用工程技能、按方法论执行，比单纯聊天更接近刚需。
- Entire 的分布式 Git 网络关注 agent 大规模 clone 和跨区域访问；这类基础设施还早，但信号明确：AI 编码正在改变代码托管的负载模型。

### 热门应用

- GPT-Live 是今天最强的用户侧信号：HN 讨论热度高，且官方明确强调全双工、打断、噪声处理、视觉理解。

5. **[bradautomates/claude-video](https://github.com/bradautomates/claude-video)**：GitHub 显示 951 stars today，当前 6,129 stars。它让 Claude 通过下载、抽帧、转写来“观看”视频。增长原因是视频内容进入 agent 分析链路后，可用于课程总结、产品研究、会议回放。适合研究视频到文本/视觉上下文工作流。

## 今天值得深入研究的 1 个主题

**Agent Skills 正在成为新的软件分发层。** 今天的 GitHub 日榜、Figma Design Agent、OpenDesign、Claude Code 生态都指向同一件事：用户不只需要更强模型，还需要可复用、可审计、可组合的技能包。建议重点研究三件事：技能如何声明输入输出，如何绑定本地文件/API/设计资产，如何通过测试或评测保证技能不会漂移。
