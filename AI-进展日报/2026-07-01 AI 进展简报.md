# 2026-07-01 AI 进展简报

> 覆盖窗口：优先 2026-06-30 至 2026-07-01 的新进展；资料不足处补充最近一周仍重要的发布。本文先沉淀为本地 Markdown 源文件，钉钉文档和 GitHub 提交均以此文件正文为准。

## 今日最值得关注

1. **Claude Sonnet 5 把“可自主使用工具的 Sonnet”推到默认位。** Anthropic 于 2026-06-30 发布 Claude Sonnet 5，并把它作为 Free/Pro 默认模型，同时开放 Claude Code 和 API `claude-sonnet-5`；官方强调它在浏览器、终端、工具调用和长任务上更像自主代理。影响判断：通用 coding agent 的默认模型竞争会更激烈，尤其是需要长链工具调用的任务。行动建议：把现有 Sonnet 4.6/Codex/Cursor 工作流选 2-3 个长任务做 A/B 测试，重点看中途失误率、工具调用成本和安全拒答边界。来源：[Anthropic](https://www.anthropic.com/news/claude-sonnet-5)（2026-06-30）。
2. **Google 把“图片快速生成 + 视频编辑”包装成开发者 API 工作流。** Google 于 2026-06-30 发布 Nano Banana 2 Lite 和 Gemini Omni Flash：前者主打 4 秒出图、低价图片生成，后者支持视频生成和对话式编辑。影响判断：产品图、广告素材、教程短视频会进入更低成本的“图生视频”流水线。行动建议：用 AI Studio 或 Gemini API 做一个“产品截图/海报 -> 10 秒视频”的小样，先验证人物一致性、文字保真和后期修正成本。来源：[Google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni-flash-nano-banana-2-lite/)（2026-06-30）。
3. **Figma 和 Open Design 都在把设计生成推向“可控的设计系统 + 可执行代码”。** Figma 在 Config 2026 发布 Code Layers、Motion、Design Agent、shader/generative plugins 和 MCP/skills 上下文能力；Open Design 0.12.0 则推出品牌背书设计系统、DESIGN.md、Figma 导入和导出能力。影响判断：设计生成的关键不再是单次出图，而是能否复用品牌约束、组件语义和代码落地。行动建议：为自己的产品沉淀一份 DESIGN.md/品牌约束，并用同一 prompt 比较 Figma Agent、Open Design、Claude/Codex 产出的可维护性。来源：[Figma Config recap](https://www.figma.com/blog/config-2026-recap/)（2026-06-24）、[Figma Design Agent](https://www.figma.com/blog/agent-custom-tools-context-skills/)（2026-06-24）、[Open Design](https://github.com/nexu-io/open-design)（2026-06-26）。
4. **Cursor iOS 公测把“云端 coding agent”带到移动端。** Cursor 3.9 iOS App 于 2026-06-29 公测，支持启动 always-on cloud agents、接管本地 agent、语音输入、查看 diff/日志/截图、合并 PR。影响判断：开发者工具正在从 IDE 插件变成异步任务控制台，移动端会放大“随时发起任务”的管理需求。行动建议：如果团队启用移动端 agent，应先规定仓库权限、PR 合并规则、敏感文件禁区和人工确认节点。来源：[Cursor changelog](https://cursor.com/changelog/ios-mobile-app)（2026-06-29）、[Cursor blog](https://cursor.com/blog/ios-mobile-app)（2026-06-29）。
5. **RAG/Agent 数据层的竞争从“向量库”升级为“可治理上下文平面”。** Couchbase 于 2026-06-30 宣布 AI Data Plane 自托管 GA，包含 Agent Memory、MCP Server 和 Agent Catalog；MongoDB 同日发布 Voyage AI、Hybrid Search、Native Reranking、Search/Vector Search 本地化能力。影响判断：生产 agent 的瓶颈正在转向上下文质量、权限边界、记忆持久化和检索可解释性。行动建议：把当前 RAG 系统按“采集、清洗、混合检索、重排、权限、记忆、评测”拆成清单，优先补齐可观测和重排评测。来源：[Couchbase](https://www.couchbase.com/blog/your-ai-agents-are-stuck-in-pilot-its-a-data-problem-not-a-model-problem/)（2026-06-30）、[MongoDB](https://www.mongodb.com/company/newsroom/press-releases/mongodb-delivers-accurate-ai-retrieval-wherever-enterprise-data-lives)（2026-06-30）。
6. **MCP 安全成为代理落地的硬门槛。** Microsoft 2026-06-30 更新 MCP Security 2026 报告，强调 tool description、schema、tool output、凭据和本地 server 都是攻击面，风险包括 tool poisoning、confused deputy、shadow MCP、命令注入和供应链替换。影响判断：MCP 不再只是接工具的便利协议，而是企业 agent 安全边界的一部分。行动建议：将 MCP server 纳入资产清单，要求工具 schema 审查、最小权限、OAuth audience-bound tokens、人审高风险调用和 gateway 日志。来源：[Microsoft Security](https://techcommunity.microsoft.com/blog/microsoft-security-blog/the-state-of-mcp-security-in-2026/4531327)（2026-06-30 更新）。
7. **Kong KAi v2 展示了企业 agent 从“问答”进入“有审批的变更执行”。** Kong 于 2026-06-30 发布 KAi v2，Konnect 助手可通过 MCP 创建、更新和删除资源，并生成 decK/Terraform 配置、构建分析看板，写操作受 RBAC、区域边界和人工确认控制。影响判断：API/运维类 agent 会优先在“有结构化资源模型 + 可回滚配置”的场景落地。行动建议：可以拿非生产 API 网关或内部平台做试点，重点验证审批、审计和回滚链路。来源：[Kong](https://konghq.com/blog/product-releases/kai-v2-agentic-platform-assistant)（2026-06-30）。
8. **AI for Science 同时出现工作台化和评测化趋势。** Anthropic 发布 Claude Science beta，面向 macOS/Linux 的科研工作台支持本地/SSH/HPC/Modal、60+ 科研 skills/connectors 和审稿 agent；OpenAI 发布 GeneBench-Pro，用 129 个计算生物学问题评估模型的研究判断。影响判断：AI 科研产品不只拼模型分数，还在拼可审计工作流、领域工具接入和结果可信度。行动建议：关注“领域 skill + 可复现 notebook + reviewer agent”的组合，把它迁移到企业分析、法务、医疗等高风险知识工作。来源：[Anthropic Claude Science](https://www.anthropic.com/news/claude-science-ai-workbench)（2026-06-30）、[OpenAI GeneBench-Pro](https://openai.com/index/introducing-genebench-pro/)（2026-06-30）。

## 分领域进展

### 设计生成

- **Figma 的方向是把 AI 嵌入现有设计画布。** Code Layers 让设计层与代码层双向转换，Motion 提供时间线和动画代码导出，Design Agent 可使用附件、Figma 文件、网页搜索、MCP connector 和自定义 skills。对产品团队来说，这比“生成一张漂亮图”更接近真实交付链路。
- **Open Design 的方向是本地优先、开源和多 CLI 编排。** 0.12.0 的 Brand-backed Design System 支持从品牌 URL、DESIGN.md、离线 `.fig` 或浏览器剪藏生成可复用设计系统；仓库在 2026-06-30 仍有提交，社区热度高。适合试验“设计系统即上下文”的开源方案，但生产落地仍要看生成代码质量和导出一致性。
- **Google 新视频模型会推动设计资产向短视频素材扩展。** Nano Banana 2 Lite 适合快速生成产品图、场景图和广告草图；Gemini Omni Flash 支持视频生成/编辑，但当前 API 仍有 10 秒长度、角色一致性和视频引用处理限制。适合做低成本预演，不适合直接替代高保真品牌大片。

### 数据采集/RAG

- **MongoDB 把检索质量打成平台能力。** Voyage-context-4、Hybrid Search、Native Reranking 和本地/私有云 Search/Vector Search 说明企业 RAG 需要同时处理长文档、关键词、语义和重排。Native Reranking 官方称可带来最高 30% 检索质量提升，值得在自己的语料上实测。
- **Couchbase 把 agent memory、MCP 和 catalog 合并到数据平面。** 这反映了一个趋势：agent 生产化不只是“向量库 + prompt”，还要处理持久记忆、边缘同步、权限、实时上下文和工具目录。
- **Firecrawl 生态在迁移到 v2 SDK，但官方近 24-48 小时未检索到重大新发布。** CAMEL 于 2026-06-10 合并 Firecrawl v2 loader，加入 `search()` 并迁移到 firecrawl-py v4；这说明开源 agent 框架仍在把网页抓取作为基础 loader。今天更值得关注的是抓取工具的兼容层和安全默认值，而不是单一爬虫的 feature list。
- **CRW/fastCRW 和 Crawl4AI 代表开源抓取工具的两个方向。** CRW/fastCRW 2026-06-28 发布 v0.19.0，主打 Rust、MCP server、Firecrawl-compatible v2 endpoints 和反爬策略；Crawl4AI 2026-06-18 v0.9.0 强调 Docker server 安全加固。两者都可试，但需要用自己的目标站点、反爬场景和合规要求压测。

### Agent 工作流

- **Cursor iOS 说明 coding agent 的控制台正在跨设备化。** 这会提高异步任务启动频率，也会放大误合并、权限过宽、任务上下文不足的问题。
- **Kong KAi v2 说明企业 agent 的下一步是受控写操作。** 它通过 MCP、RBAC、区域边界和人工确认把 API 管理从问答推进到变更执行。
- **Microsoft MCP 安全报告给了落地检查表。** 生产前至少要明确：哪些工具可信、哪些输出必须当作不可信输入、谁能授权工具调用、凭据是否最小化、是否能检测 tool drift。
- **OpenAI 对 agent 使用的研究显示长任务正在真实发生。** OpenAI 2026-06-25 报告称，截至 2026-05，许多用户已经把 Codex 用在超过 30 分钟、1 小时甚至 8 小时的人类工作量任务上。结论是：agent 不是单轮补全工具，而是需要任务设计、验收标准和审计记录的执行系统。

## 今天值得深入研究的 1 个主题

**主题：Agent 生产化的核心问题正在从模型能力转向“可治理上下文层”。**

今天的几条新闻可以串成一条线：MongoDB 和 Couchbase 在争夺 agent 的检索、记忆和数据平面；Microsoft 强调 MCP 工具、输出和凭据都是攻击面；Kong 把 agent 写操作放进 RBAC、审批和 IaC 产物；Figma/Open Design 把品牌和设计系统作为生成上下文；Cursor iOS 则让 agent 执行入口更轻、更频繁。

建议深入研究三个问题：

1. **上下文从哪里来：** 抓取、内部文档、设计系统、代码库、数据库、运行日志分别如何进入 agent？
2. **上下文如何被验证：** 是否有混合检索、重排、引用、权限过滤、过期检测和任务级评测？
3. **agent 何时可以写：** 哪些动作只能建议，哪些动作可以生成 PR，哪些动作可以在人工确认后直接改配置？

如果要做一个可复用研究产物，建议画一张“Agent Context Plane”架构图，把采集/RAG、记忆、工具/MCP、权限、安全审计、执行审批、回滚和评测放在同一张图里。

## 可忽略的噪音

- 社交平台上“某某设计工具已完全替代设计师”“Claude Design 被免费克隆”等短视频标题，通常缺少可复现 demo、版本信息和真实导出质量评估。
- SEO 工具榜单和“十大 AI 工具”合集，多数把旧功能重新包装为新品；除非有官方发布日期、release note 或可试用入口，否则不纳入重点跟踪。
- 未经官方博客、模型卡、API 文档或可信仓库验证的模型价格、发布日期和跑分搬运，今天不作为判断依据。
- 单纯展示 prompt 生成 UI 截图但不提供设计系统、组件复用、代码导出、响应式验证和版权说明的案例，暂不视为高价值设计生成进展。
