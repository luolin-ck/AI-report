> 本次已检查：MCP 官方 `latest` 规范页、versioning 页、Build with Agent Skills 页面、Claude `mcp-server-dev` plugin 页面、MCP Apps 构建页和相关官方/权威目录。未将第三方 skill 集合冒充为官方更新。

- **当前基线：2026-07-28。** 规范页显示 MCP base protocol 采用 JSON-RPC、stateless self-contained requests、per-request capability negotiation；extension 包括 Tasks、Skills over MCP、MCP Apps。来源：[MCP Specification](https://modelcontextprotocol.io/specification/2026-07-28)。
- **Build with Agent Skills 基线未变。** 官方页面仍列出 `mcp-server-dev` plugin 的三个 composing skills：`build-mcp-server`、`build-mcp-app`、`build-mcpb`。来源：[Build with Agent Skills](https://modelcontextprotocol.io/docs/develop/build-with-agent-skills)。
- **`mcp-server-dev` plugin 当前公开信息。** Claude 插件页显示它由 Anthropic 制作、Anthropic Verified、安装到 Claude Code，公开安装数为 33,959；功能仍是设计和构建 MCP servers，覆盖 HTTP、MCPB、local、tools、auth、interactive apps。来源：[Claude MCP Server Dev Plugin](https://claude.com/plugins/mcp-server-dev)。
- **技能用途与能力变化**：
  - `build-mcp-server`：入口 skill，先询问 use case，再选择部署模型、tool design pattern、framework，并 scaffold 项目。
  - `build-mcp-app`：为 MCP server 增加 forms、searchable pickers、confirmation dialogs、charts、live status 等 inline UI。
  - `build-mcpb`：把本地 stdio server 和 runtime 打包为 `.mcpb`，让用户无需安装 Node/Python 即可使用。
- **迁移影响**：新 MCP server 应优先按 2026-07-28 的 stateless 请求、`server/discover`、header-based routing、cacheable list results 和 Tasks/MCP Apps/Skills extension 设计；旧 handshake/session/SSE 路径仍需迁移计划。
- **适合谁试用**：包装云 API 的平台团队、构建企业内部 tool server 的工程团队、需要 chat 内交互 UI 的 MCP App 开发者、需要本地文件/桌面能力的 MCPB 作者。
- **行动建议**：本周无需因新协议版本做紧急升级；应把重点放在按 `mcp-server-dev` 的发现阶段重新审视 tool 边界、OAuth/权限、危险动作确认、日志审计和打包分发方式。

## 今天值得深入研究的 1 个主题

**Agent Skills 的供应链安全与团队治理。**

今天 GitHub Trending 的前排项目很集中：Codex、skills、free Claude/Codex、Hermes Agent、ECC、book-to-skill、awesome-agent-skills 都在争夺“如何让 agent 更能干、更便宜、更可复用”。问题是，skill 本质上是会影响 agent 行为的指令和脚本包，供应链风险比普通 README 更高。

建议本周做一个小研究：选 5 个高热 skill 仓库，逐个检查 `SKILL.md` 触发条件、脚本、网络调用、权限要求、是否读取 secrets、是否要求执行未知命令、是否有验证步骤。输出一份团队 skill 安装规范：默认只读、先审后装、禁止自动执行高危动作、所有外部网络和凭据访问必须显式批准。

## 可忽略的噪音

- **把安全事件写成“AI 已经失控”的标题党。** OpenAI/Anthropic 的真实信号是沙箱、监控、RL training、cyber capability threshold 和访问控制，值得复盘；耸动标题不值得传播。
- **只看 GitHub 总 stars 的排行榜。** 本日报使用 `stars today` 作为近期热度口径；总 stars 高只能说明历史影响力，不代表今天增长最快。
- **未经审计的免费 Claude/Codex token 工具。** 成本压力是真需求，但企业场景必须审查 ToS、凭据、数据流向、代理服务和日志。
- **AI 设计工具首屏 demo。** 真正需要验证的是可编辑性、设计系统一致性、响应式、交付到代码/素材库的路径，以及后续维护成本。
- **无法直接核验的 X 私有互动数据。** 登录墙或第三方转述只能作为线索，不作为精确互动指标。
