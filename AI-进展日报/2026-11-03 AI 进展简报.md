## 今日最值得关注

1. **Figma 把 shader 从视觉实验推到可交付的 code layer。** [Figma 11 月 2 日发布说明](https://www.figma.com/release-notes/)显示，shader 现在可渲染/导出到最高 4096px，并可通过 “build this with code” 带入 code layer；shader 同时面向所有用户 GA。**影响：**生成式视觉与可运行原型的断层继续缩小。**行动：**用同一品牌页面比较 shader 在画布、导出和 Chrome 157 code layer Play 模式中的视觉一致性、性能和降级表现。
2. **OpenAI 用 LifeVal 把 Agent 评测从“答对问题”转向“完成生活任务”。** [LifeVal](https://openai.com/index/lifeval/)基于时间使用研究与 3,995 人代表性调查，覆盖照护、健康、教育、财务、购物和政府服务。**影响：**个人 Agent 的竞争指标开始包含浏览器、计算机和 connector 的端到端行动。**行动：**把自己的高频生活/办公流程做成可回放任务，分别记录完成率、人工接管点、副作用和最终效用；官方示例分数未在本次研究中独立复现。
3. **OpenAI 为 Agent 并发开发重建了 Git 后端。** [Pando 工程文章](https://openai.com/index/scaling-git-at-openai/)称其保留 Git 协议兼容，以按分支独立协调写入和复用 packfile 扩展读写；生产中 median push latency 下降近 5 倍、每日传输近 1 PB。**影响：**多 Agent 并行的瓶颈正从模型转向源码控制、CI 和合并基础设施。**行动：**在自己的仓库量化并发分支数、push/fetch 延迟、CI 扇出和合并冲突；官方生产数据不等于通用 Git SLA。
4. **Firecrawl 在“公开索引 + 企业数据流”两端同时加速。** [11 月 2 日 changelog](https://www.firecrawl.dev/changelog)把 Government Index 限额提高到每分钟 300 次、仍不消耗 credits；同时推出面向 ChatGPT/Claude 的 headless Clay，可搜索 2.5 亿+人和 2,600 万+公司并运行 enrichment flow。**影响：**RAG/研究 Agent 的数据层正从网页抓取扩展到可计费、可追溯的专用数据源。**行动：**先用政府索引测试权威引用与时间过滤；人员/公司 enrichment 涉及隐私和授权，只在明确用途、最小字段与留痕条件下试用。
5. **Cloudflare AI Search 改了成本日期与默认新鲜度。** [Cloudflare 11 月 2 日 AI changelog](https://developers.cloudflare.com/changelog/product-group/ai/)将计费启动从 11 月 1 日推迟到 12 月 1 日，并把默认同步间隔从 6 小时改为 24 小时（仍可配置 15 分钟到 24 小时）。**影响：**默认值会直接改变 RAG 新鲜度，而不仅是账单。**行动：**对新闻、价格、库存等时效源显式设置 `sync_interval`，不要依赖默认值；同时在 12 月前完成容量和成本压测。

- **Figma shader → code layer（11 月 2 日）。** 最高 4096px 导出、code layer 内渲染和全量 GA，使材质/动效不再只停留在静态概念图；浏览器内 code layer 路径要求 Chrome 157，且正在滚动上线。[官方来源](https://www.figma.com/release-notes/)。适合视觉原型、品牌互动页和数据艺术团队测试，但要单独验收帧率、fallback 和可访问性。
- **Figma Google Drive connector（近 7 日补充，10 月 30 日）。** 同一发布页显示，Figma agent/Make 可读取 Drive 研究、引用真实数据、拉取素材并创建 Drive 文件，connectors 已下放到 Starter 等全部计划。[来源](https://www.figma.com/release-notes/)。这使“研究资料—画布—原型”成为一条 Agent 链，团队应先限制可访问文件夹和写入范围。
- **本窗口未发现 OpenDesign 或 Claude Design 的重大官方新品。** 不重复把 10 月中下旬的 Code Layers、Brush、Canva Craft 等旧闻包装为今日发布；本轮设计生成的真实新增点是 shader 的高分辨率与 code layer 交付路径。

- **Firecrawl Government Index：300 次/分钟、零 credits。** 限额是原来的 3 倍，适合高频法律、监管、许可和公共记录检索。[官方 changelog](https://www.firecrawl.dev/changelog)，2026-11-02。应保存具体页面 URL、检索时间和法规版本，不把索引召回当法律结论。
- **Firecrawl headless Clay：Agent 直接运行 enrichment flow。** 官方称可在 ChatGPT/Claude 搜索 2.5 亿+人和 2,600 万+公司，并提供每月 1,000 免费 credits。[来源](https://www.firecrawl.dev/changelog)，2026-11-02。它更接近受控数据连接器而非普通 crawler；适合销售研究/公司情报，不适合绕过隐私、用途限定或组织授权。
- **Cloudflare AI Search：默认同步由 6 小时放宽到 24 小时。** 这对变化快的数据是潜在回归，对静态知识库则能降低同步压力。[来源](https://developers.cloudflare.com/changelog/product-group/ai/)，2026-11-02。建议把 freshness 写成数据源级 SLO，并对过期答案设置拒答/回源策略。
- **Scrapling 登上 GitHub 日榜。** [D4Vinci/Scrapling](https://github.com/D4Vinci/Scrapling)覆盖从单请求到全站 crawl，说明可自托管抓取框架仍有强需求。适合抓取团队做反爬适配与 DOM 变化回归，但必须遵守 robots、站点条款、速率和个人数据边界。

## 今天值得深入研究的 1 个主题

### Agent-scale 的真正瓶颈：从模型能力转向“上下文、数据与并发写入”

LifeVal 要求 Agent 真正完成跨网站和工具的生活任务；Pando 则说明并发 Agent 会迅速放大分支、push、fetch、CI 和合并压力；Cloudflare/Firecrawl 的更新又表明，知识新鲜度、专用索引和数据权限会直接决定结果。下一步不应只比较模型分数，而应选一个真实流程，同时记录四组指标：事实新鲜度与引用完整性、工具权限与副作用、并发写入/冲突/恢复、用户最终获得的时间与质量收益。
