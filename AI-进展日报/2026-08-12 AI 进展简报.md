## 分领域进展

### 设计生成

- Figma 的近期官方更新表明，AI 设计生成正在进入“代码与设计系统闭环”阶段。2026-07-16 更新提到，将 Make preview、Figma MCP server 生成的 design from code、Chrome extension 捕获的 live web page 带回 Figma canvas 时，颜色、字体和间距会尽量绑定到文件变量，而不是落成硬编码值；更多 frame 也会带 Auto Layout。2026-07-24 的 Auto Layout 更新则进一步缩小 Figma canvas 与 CSS 布局的差异。
- 这对产品团队的意义很具体：AI 生成的页面如果不能绑定变量、组件和 Auto Layout，它只是一次性草图；如果能进入 design system 和 code review，它才可能变成团队生产力。建议用一个真实业务页面做小样本测试：同一设计系统下生成页面、带回 Figma、交给前端实现，再记录返工项。
- Claude Design 本轮未发现 24-48 小时内官方新版，但第三方教程和整理页仍显示很强的长尾传播。FableGuide 的 Claude Design YouTube watchlist 在 2026-07-20 更新，按 YouTube view count 排列，列出 “Claude Design: The Complete Guide” 约 135K views、“Claude Design Just Changed Everything” 约 123K views、“Use Claude Code DESIGNER Skill to 10x UI Designs” 约 116K views 等。口径限制：这是第三方 watchlist，不是 YouTube 官方热榜；可以说明公开可见度，不能等同于全平台排名。
- OpenDesign 本轮未检索到最近一周官方新版本；它仍值得作为“本地设计生成 + coding agent + 设计系统 + Figma export”的基线方向跟踪，但今天不把它写成新增进展。

### 数据采集 / RAG

- Firecrawl 是今天数据采集/RAG 方向最强的开发者信号。GitHub Trending TypeScript 抓取时显示 `firecrawl/firecrawl` 约 165,821 total stars、1,020 stars today；官方仓库描述是 “The context API to search, scrape, and interact with the web at scale.” 这说明 web context API 仍是 agent/RAG 的刚需入口。
- Firecrawl 官方 changelog 最新可核验的核心产品更新是 2026-07-22 `/search` 升级：自定义相关性模型会按 query 评分段落、列表和表格，返回更适合回答问题的 excerpts；官方称 agent 使用 `/search` 在 SimpleQA 达 94.7%，且比处理全文减少 10x token。口径限制：这是 Firecrawl 官方指标，仍需要用自己的语料和查询集验证。

- 中文社媒/内容采集方面，`NanmiCoder/MediaCrawler` 本轮在 GitHub Trending Python 中显示约 61,694 total stars、933 stars today。它覆盖小红书、抖音、快手、B 站、微博、贴吧、知乎等内容/评论抓取。适合研究数据采集场景，但必须严格遵守平台条款、robots、隐私与法律边界，不应直接用于违规采集。

### Agent 工作流

- Prime Agent 是今天最强 coding agent 开源信号。GitHub Trending TypeScript 显示 `PrimeIntellect-ai/prime-agent` 约 14,034 total stars、1,148 stars today；项目 README 将它定位为 open-source coding and research agent for general and long-running work，核心是 Recursive Language Model、Continual Harness、persistent Python control environment、subagents、skills、daemon-backed sessions、heartbeats 和 schedules。
- Prime Agent 值得跟踪的不是“又一个 coding agent”，而是它把 memory、skills、subagents、long-running tasks、自动压缩和 session 续跑组合成一个 harness。这是 coding agent 从单轮补丁走向长期任务编排的典型形态。风险同样明确：README 提醒它会以用户权限执行模型生成的 Python 和项目命令，因此测试必须放在隔离仓库和最小权限环境。
- `stablyai/orca` 在 GitHub daily 页面显示约 42,707 total stars、881 stars today，定位为 “ADE for working with a fleet of parallel agents”，可用自己的订阅运行 coding agent，并覆盖 desktop/mobile/VPS。它代表 “agent desktop / agent control plane” 方向：用户不只需要一个模型，还需要管理并行 agent、订阅、状态和工作区。
- `paperclipai/paperclip` 在 daily 页面显示约 77,125 total stars、743 stars today，定位为开源 agent 管理应用。这个方向适合企业试点，因为多 agent 真正落地后，谁在跑、跑了什么、花了多少钱、是否需要审批，会比单个模型选择更重要。

### 热门应用

- 本地/私有 agent：Meta Muse Glimmer 的传播价值在于把“open-weight + laptop/PC + agentic tasks”重新推到前台。适合想减少云依赖、处理敏感代码、做边缘设备或离线任务的团队观察。注意先看官方模型卡、许可证、硬件要求和安全说明，再决定是否试用。
- Web context/RAG：Firecrawl 的热度来自真实工程痛点：搜索、抓取、解析、监控、PDF、结构化输出都很难稳定拼起来。适合 RAG、AI 搜索、竞品监控、研究 agent、销售情报和知识库摄取团队。
- AI 设计生成：Figma Make、Figma MCP、Claude Design、OpenDesign 的共同问题已经变成“设计系统约束和 code handoff”。适合产品、设计系统和前端团队做闭环试点，不适合只追求一张漂亮截图。
- Agent skills：`anthropics/skills`、`addyosmani/agent-skills`、`mcp-server-dev` 和多家厂商的 skill 目录说明，开发者正在把高频工作流沉淀成可加载的 `SKILL.md`。适合内部平台团队把 PR review、发布检查、数据摄取、设计走查等流程做成可审计 skill。
- AI browser / automation：Product Hunt AI topic 最近列出 AI Browser、Raydian、Klariqo AI Voice Assistants 等 recent launches，说明 “浏览器自动化、chat-to-build、语音/客服 agent” 继续是创业产品热点。口径限制：Product Hunt topic 页是产品发现/分类口径，不代表全网热榜。

## 今天值得深入研究的 1 个主题

**Agent 安全发布清单：从工具权限到网络隔离。**

过去一周的 OpenAI Astra 延迟、Meta 测试事故、The Guardian 的 AI 安全公开信，以及 GitHub 上 Prime Agent/Firecrawl/agent skills 的高热度，都指向同一个问题：agent 正在获得越来越多外部行动能力，但很多团队的发布流程仍停留在 chatbot 时代。值得单独做一次内部研究：

- 权限面：agent 能否读本地文件、读取环境变量、访问浏览器登录态、调用邮件/日历/Slack、写 GitHub、触发支付或部署。
- 网络面：默认出网、allowlist、denylist、web fetch/scrape、浏览器自动化、第三方 API token 使用。
- 执行面：代码执行、shell 命令、Python/Node notebook、生成脚本是否进入人工 review。
- 审计面：每个 tool call 的输入、输出、用户批准、外部写操作、失败重试、异常中断是否可追踪。
- 评测面：用真实业务任务构造红队样本，包括 prompt injection、恶意网页、钓鱼邮件、伪造 issue/PR 评论、跨组织数据泄露。

建议本周产出一个最小可用清单：哪些动作可以自动、哪些必须批准、哪些永不允许；再把清单编码进 agent harness、MCP server 和 skill 触发规则。
