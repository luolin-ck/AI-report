## 今日最值得关注

1. **GPT-5.6 与 ChatGPT Work 是本周主线。** 办公、代码、文档、轻应用生成继续合流；建议用真实任务测 Sol/Terra/Luna 的成本和稳定性。来源：[Axios](https://www.axios.com/2026/07/09/ai-openai-gpt-release)、[The Verge](https://www.theverge.com/ai-artificial-intelligence/963464/openai-gpt-5-6-codex-chatgpt-work)。
2. **Figma Make 接入 GPT-5.6 后，设计到代码更看首轮可运行质量。** 影响：AI 设计生成从出图转向可交互原型。行动：用真实 Figma 文件测一次静态稿到 working build。来源：[Figma](https://www.figma.com/blog/gpt-5-6-is-now-available-in-figma-make/)。
3. **设计系统正在变成 Coding Agent 上下文层。** Figma MCP + Storybook + skill 能减少设计/开发解释成本。行动：把组件状态、变量、用法约束整理成 agent 可读文档。来源：[Figma Decagon](https://www.figma.com/blog/how-decagon-uses-ai-for-design-system-saturation/)。
4. **Firecrawl `/monitor` 推动 RAG 抓取从 URL 巡检变成全网发现。** 建议给关键主题设置 24h monitor，并写清 goal。来源：[Firecrawl Docs](https://docs.firecrawl.dev/features/monitoring-web-scale)。
5. **Agent 安全风险扩展到数据注入、仓库名幻觉和审批绕过。** 只点“确认”不够；要限制写盘/联网权限，固定依赖 URL，执行前独立校验。来源：[ITPro](https://www.itpro.com/security/flaws-in-some-of-the-most-popular-ai-coding-tools-left-developers-wide-open-to-attack)、[ADI](https://arxiv.org/abs/2607.05120)、[HalluSquatting](https://arxiv.org/abs/2607.07433)。
6. **GitHub 今日 AI 热榜偏向 agent skill、知识图谱、spec 工作流。** Graphify、Vibe-Trading、awesome-llm-apps、hallmark、spec-kit 说明开发者在追可复用流程资产。
7. **YouTube 公开热度集中在 GPT-5.6/ChatGPT Work 与 Codex+Claude Code。** OpenAI 官方视频与 Riley Brown 视频传播较快；重点复盘任务拆解方式，不照抄标题党承诺。

## 分领域进展

### 设计生成

- **Figma Make + GPT-5.6**：官方强调从 prompt 到 working build 的速度、从已有 Figma 文件生成交互原型、以及错误自修复。适合产品经理/设计师快速验证复杂交互，但仍要人工检查响应式、状态和可访问性。
- **Figma MCP + 设计系统**：Decagon 案例的重点不是“AI 画得更好”，而是让 agent 访问组件库、Storybook 和设计上下文，减少设计/开发来回解释。值得关注的落地点是 `design.md`、组件用法约束和可复用 skill。
- **Claude Design / OpenDesign 类工具**：近期社区讨论集中在“导入设计系统生成 landing page、slides、培训材料”。口径限制：我未拿到 Anthropic 官方 Claude Design 页面，本日报只把它作为社区实践趋势，不当作今日官方发布。
- **Hallmark**：GitHub 今日热榜中的 [Nutlope/hallmark](https://github.com/Nutlope/hallmark) 是给 Claude Code、Cursor、Codex 使用的 anti-AI-slop design skill，说明“审美/设计质量约束”正在被工程化成 agent skill。

#### 生图 / 生视频 Agent 技术与热议 skill/prompt

- **ComfyUI 变成 Agent 可控运行时**：[COMFYCLAW](https://arxiv.org/abs/2607.01709)（2026-07-02）把生图拆成 typed graph editing、运行反馈、VLM 验收和可复用 skills；[MemoGen](https://arxiv.org/abs/2606.03243) 强调把成功/失败样本写入经验记忆。值得试：把海报、商品图、UI mockup 工作流沉淀成 skill。
- **生视频从“文生视频”转向“可编辑镜头”**：[Runway Aleph](https://runwayml.com/research/introducing-runway-aleph) 支持加删/变换对象、换角度、改风格和光照；Google [Veo 3.1 + Flow](https://blog.google/innovation-and-ai/products/veo-updates-flow/) 强调参考图、首尾帧、Extend、Insert/Remove 与音频。建议：先写 shot list、角色/物体 reference、镜头约束，再分段生成和复核。
- **热门 skill/prompt 的核心是质量门**：[Hallmark](https://github.com/Nutlope/hallmark) 做 anti-AI-slop 设计 skill；[awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 把品牌视觉拆成 `DESIGN.md`；[agent-skills](https://github.com/addyosmani/agent-skills) 把流程、红旗、验收证据写进 skill。团队可沉淀“风格锚点 + 禁用套路 + 截图验收 + 可访问性检查”。
- **热议 prompt 资产要抽象复盘，不照搬**：[system_prompts_leaks](https://github.com/asgeirtj/system_prompts_leaks) 传播快，说明大家在学习产品级提示结构；更安全的复盘对象是角色边界、工具权限、失败处理、输出格式和验收标准。[/watch / claude-video](https://github.com/bradautomates/claude-video) 这类视频理解 skill 则适合把竞品广告转成 shot bible，再交给 Runway/Veo/ComfyUI 做变体。

### 数据采集 / RAG

- **Firecrawl web-scale `/monitor`**：从 URL diff 扩展为全网查询发现；支持 `searchWindow`、`maxResults`、domain filters、goal judging。适合 RAG 增量入口。
- **Firecrawl 动态抓取定位**：官方 2026 dynamic scraping 文章强调 JS rendering、Markdown/JSON 输出和 RAG-ready 内容。对 AI 应用来说，抓取工具的价值不再只是拿 HTML，而是减少清洗和 chunk 前处理。
- **Graphify**：今日热榜的 [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) 把代码、SQL schema、文档、论文、图片、视频转成可查询知识图谱，适合大型代码库问答和跨资料 RAG。

### Agent 工作流

- **ChatGPT Work**：媒体报道定位为更通用的多步骤工作代理，和 Codex 的代码执行能力形成连通。建议把它当“任务执行环境”评估，而非普通聊天模型。
- **Loop engineering**：近期视频和论文都在强调“少手写 prompt，多设计 trigger、goal、verification、stopping rule、memory”。适合日报、CI 修复、资料监控。
- **Spec-driven development**：[github/spec-kit](https://github.com/github/spec-kit) 今日仍在热榜，README 将规格说明提升为可执行输入，适合和 Codex/Copilot 类工具配合，减少“需求没写清导致 agent 自由发挥”。
