### MCP / Agent Skills 更新

**本次核验结论：未发现官方新版/技能更新。** 截至 9 月 18 日 11:15 CST，[MCP 官方版本页](https://modelcontextprotocol.io/docs/2026-07-28/learn/versioning)仍将 `2026-07-28` 列为 Current；[GitHub release 页](https://github.com/modelcontextprotocol/modelcontextprotocol/releases)最新稳定版本同为 `2026-07-28`。[Build with Agent Skills](https://modelcontextprotocol.io/docs/2026-07-28/develop/build-with-agent-skills)、[Skills 扩展概览](https://modelcontextprotocol.io/extensions/skills/overview)、[ext-skills 稳定规范](https://github.com/modelcontextprotocol/ext-skills/blob/main/specification/stable/skills.mdx)与 [mcp-server-dev 官方插件](https://github.com/anthropics/claude-plugins-official/blob/main/plugins/mcp-server-dev/README.md)本次未查到可核实的 9 月 17—18 日新版发布记录。9 月 13 日 SEP-2640 Final 已在昨日简报记录，本次保持基线，不重复当成新发布。

- **当前协议基线**：`2026-07-28` 提供无会话核心、每请求 `_meta`/`MCP-Protocol-Version`、`server/discover`、MRTR、列表缓存与更明确的授权边界。迁移时要同时兼容旧版本客户端，不能只替换握手字段。来源：[规范变更](https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/docs/specification/2026-07-28/changelog.mdx)。
- **Skills 扩展基线**：`io.modelcontextprotocol/skills` 要求 server 声明 Resources 和该扩展，提供 `skills/list`、`skills/get`，实际文件经 `resources/read` 读取；manifest 含 URI、SHA-256 digest、size，列表和读取结果带 TTL/cache scope。适合做跨客户端能力发现、动态技能目录；迁移旧实验实现时要移除 `skill://index.json`/压缩包假设，按 server 身份与 URI 组合标识技能，按宿主审批路径加载。来源：[官方概览](https://modelcontextprotocol.io/extensions/skills/overview)、[稳定规范](https://github.com/modelcontextprotocol/ext-skills/blob/main/specification/stable/skills.mdx)。
- **开发技能清单基线**：[mcp-server-dev](https://github.com/anthropics/claude-plugins-official/blob/main/plugins/mcp-server-dev/README.md)仍是 `build-mcp-server`（部署模型、工具模式与鉴权设计入口）、`build-mcp-app`（聊天内交互 UI）、`build-mcpb`（把本地 stdio server 连运行时打包）三项；未发现这三项在本次窗口新增/改名。另有 MCP 官方 [ext-apps Agent Skills](https://github.com/modelcontextprotocol/ext-apps/blob/main/docs/agent-skills.md) 的 `create-mcp-app`、`migrate-oai-app`、`add-app-to-server`、`convert-web-app` 四项；它们是 MCP Apps 建造/迁移技能，不应混称 mcp-server-dev 的新增技能。
- **行动建议**：MCP 服务作者先按 `build-mcp-server` 决定远程 HTTP、本机 stdio 或 MCPB；需要界面再用 `build-mcp-app`。已有 Apps 的团队试 `migrate-oai-app` 或 `add-app-to-server`，并核验宿主支持、manifest 变更和权限审批。
