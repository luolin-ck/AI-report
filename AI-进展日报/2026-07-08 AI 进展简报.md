## 今日最值得关注

1. **Claude Cowork 从桌面走向手机和 Web，Agent 开始变成“随时待命的工作流”。**  
   The Verge 7 月 7 日报道，Claude Cowork 首次登陆移动端和 Web，Max 用户优先，云端会话成为默认选项，任务可在笔记本关闭后继续运行，手机会收到需要确认的通知。[来源](https://www.theverge.com/ai-artificial-intelligence/961978/anthropic-claude-cowork-mobile-web)  
   **影响判断**：Agent 的竞争焦点从“能不能调用工具”变成“能不能跨设备、跨时段持续执行”。  
   **行动建议**：把常用研究、整理资料、会议准备、文件归档流程拆成可审核的任务模板，先用低风险资料试运行。

2. **Figma 把 AI 设计能力往可交付工程材料推进。**  
   Figma Config 2026 更新包括 Code Layers、AI motion、WebGPU shader、Weave workflows、agent skills 和 generative plugins。[来源](https://www.theverge.com/tech/955831/figma-code-design-tools-config-2026-announcements)  
   **影响判断**：设计生成不再只是“出图”，而是更接近“设计、动效、代码、素材工作流”的一体化画布。  
   **行动建议**：团队评测 AI 设计工具时，不只看首屏颜值，要测组件复用、动效可编辑、代码同步和设计系统约束。

3. **低价 Agent 模型继续施压：GLM-5.2 的话题中心是成本，而不只是跑分。**  
   The Atlantic 7 月 7 日报道，Z.ai 的 GLM-5.2 因编码和 Agent 能力、低成本、OpenRouter 可用性受到硅谷关注。[来源](https://www.theatlantic.com/technology/2026/07/glm-5-2-china-cheap-ai-agents/687828/)  
   **影响判断**：企业会更认真地做“强模型 + 便宜模型”的分层路由。  
   **行动建议**：把任务按风险分层：规划/审批用高可信模型，批处理、候选生成、低敏代码任务可试更低成本模型。

4. **AI 抓取/RAG 的核心矛盾正在变成“Agent 如何合法、稳定地访问网页”。**  
   arXiv 6 月论文《Towards an Agent-First Web》提出 agent 标识、速率限制、agent-friendly 内容层、token 计费和 provenance 等原则。[来源](https://arxiv.org/abs/2606.19116)  
   **影响判断**：未来 RAG 数据采集不能只比谁抓得快，还要处理授权、身份、计费、来源可信度。  
   **行动建议**：为爬取管线加上来源 URL、抓取时间、robots/访问策略、字段校验和失败重试记录。

5. **AI Scraper 可被“金丝雀 token”识别，抓取工具需要默认可审计。**  
   5 月 arXiv 论文提出给访问者发放独特 token，再观察 LLM 输出是否含有该 token，以推断哪些 scraper 进入了模型链路。[来源](https://arxiv.org/abs/2605.13706)  
   **影响判断**：RAG/抓取产品会遇到更多反爬、合规和数据血缘要求。  
   **行动建议**：对 Firecrawl、Crawl4AI、浏览器 Agent 等工具，优先测试“可解释抽取”和“来源回溯”，不要只看成功率。

6. **CLI Coding Agent 的企业效果开始有实证数据。**  
   Microsoft 早期 2026 年大规模部署研究显示，Claude Code 与 Copilot CLI 的首次使用受社交网络影响；持续使用更取决于工程师本身编码活动；采用者合并 PR 数约高 24%。[来源](https://arxiv.org/abs/2607.01418)  
   **影响判断**：Agent 不是均匀提升所有人，而是更容易放大已有工程实践。  
   **行动建议**：企业 rollout 时要配套范例仓库、同伴示范、任务白名单和成本看板。

7. **GitHub 今日 AI 热榜偏向“实用小工具”：求职、会议、技能、视频输入、系统提示词。**  
   GitHub Trending 今日页面显示，AI 相关靠前项目包括 `ai-job-search`、`meetily`、`agent-skills`、`system_prompts_leaks`、`claude-video`。[来源](https://github.com/trending?since=daily)  
   **影响判断**：开发者在追求能直接接入 Claude Code/Codex/本地模型的轻量工作流，而不是等待大平台闭环。  
   **行动建议**：从一个低风险垂直流程试起，例如会议纪要、简历筛选、视频转写、代码审查技能。

## 分领域进展

### 设计生成

- **Figma：从 prompt-to-prototype 走向“设计画布上的工程协作”。** Code Layers 允许在 Figma Design 画布上处理代码，Motion 支持用提示词生成动效并在时间线中调整，Shaders 用 WebGPU 生成视觉效果，Weave workflows 把复杂 AI 视觉链路封装成画布工具。[来源](https://www.theverge.com/tech/955831/figma-code-design-tools-config-2026-announcements)  
  **适合尝试**：设计工程团队、需要把视觉动效交付给前端的人、想把 Figma 和代码仓库拉近的产品团队。

- **GenUI 研究给了一个冷静提醒：AI 生成界面通常可用，但容易保守。** 5 月 arXiv 研究发现，AI 生成原型在实用性上评价较好，但原创性和创新感偏弱。[来源](https://arxiv.org/abs/2605.15124)  
  **适合尝试**：早期探索可用 AI 提速；真正定稿前仍要做信息架构、品牌差异和交互细节审查。

### 数据采集 / RAG

- **Firecrawl 近 48 小时未检索到重大官方 release；其 GitHub releases 最近一次公开版本在 2026-06-19。**[来源](https://github.com/firecrawl/firecrawl/releases)  
  **判断**：本期不硬编 Firecrawl 新功能；RAG 方向更值得关注的是 agent-first web、scraper 识别和合规访问。

- **抓取管线要从“HTML 转 Markdown”升级到“浏览、交互、抽取、引用、审计”。** 网页内容方会要求身份、用途和约束，RAG 系统也要记录来源和抽取质量。  
  **适合尝试**：对重要站点建立小样本 golden set，人工标注字段，定期回归抽取准确率。

### Agent 工作流

- **Claude Cowork 云端化后，非程序员 Agent 使用门槛下降。** Wired 报道称，用户可让 Cowork 汇总邮件、Slack、会议纪要和在线信息并生成会议材料。[来源](https://www.wired.com/story/shut-those-laptops-anthropic-puts-its-claude-cowork-agent-on-your-phone/)  
  **建议**：把审批点放在“发送邮件、改文件、对外发布、删除内容”之前。

- **Codex/Claude Code 类工具要看长期任务管理，而不是单次补全。** arXiv Codex 使用研究显示，Agentic AI 使用在 2026 年上半年快速增长，并出现并行管理多个 agent、复用 skills、长任务请求增长等模式。[来源](https://arxiv.org/abs/2606.26959)  
  **建议**：建立“任务说明、执行日志、测试结果、人工验收”的固定模板。

## 今天值得深入研究的 1 个主题

**主题：Agent-first web 会怎样改变 RAG 和网页抓取。**

过去 RAG 工程主要关心“能不能抓到”和“能不能转成 Markdown”。现在更关键的是：Agent 是否有权访问、是否声明身份、是否尊重速率限制、是否能给出可追溯来源。建议今天深入研究三件事：给 RAG 管线加来源血缘和抽取质量评估；为高价值网站建立合规访问策略；把爬虫、浏览器 Agent、向量库和回答链路串起来做审计。
