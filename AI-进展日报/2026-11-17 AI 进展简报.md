## 今日最值得关注

1. **OpenAI 把“可信检索 + 插件 + 计算机操作”组合成了医疗行业 Agent 套件。** 11 月 16 日发布的 ChatGPT for Healthcare 新能力包含 20 多个医疗插件、可信临床搜索和 computer-use agents；官方同时给出人工复核、审计、角色权限等控制项。[来源：OpenAI，2026-11-16](https://openai.com/index/more-ways-to-move-care-forward-with-chatgpt-for-healthcare/)。**影响判断：**行业 Agent 的竞争点正从模型回答转向“能在既有系统里完成工作且可审计”。**行动建议：**做垂直 Agent 时，把工具许可、人工确认、全链路审计列为产品一级能力，而不是上线前补丁。
2. **Liquid d1.2 把超低价决策模型扩展到音频和结构化感知任务。** d1.2 / d1.2-ultra 新增音频输入，以及读数、区间抽取、框选定位、数值估计和多选等任务；官方定价分别为每百万输入 token 0.02 美元和 0.042 美元。[来源：Liquid AI，2026-11-16](https://www.liquid.ai/blog/d1-2)。**影响判断：**高频、窄任务 Agent 可以用小模型做路由和感知，再把少量疑难样本升级到大模型。**行动建议：**用自己的脏数据、拒答和长尾样本复测；官方榜单属于厂商报告，不能直接替代业务评测。
3. **GitHub Copilot 开始治理“Agent 自定义能力的供应链”。** 新增 `strictPluginOnlyCustomization` 管理设置，可要求 skills、custom agents、hooks、MCP servers 和可执行扩展只能来自插件或托管设置；如需市场白名单，还要配合 `strictKnownMarketplaces`。[来源：GitHub，2026-11-16](https://github.blog/changelog/2026-11-16-control-where-github-copilot-customizations-come-from/)。**影响判断：**企业采购 Agent 的审查对象将从“哪个模型”扩大到“技能、MCP 与插件从哪里来”。**行动建议：**盘点现有技能来源、签名/版本锁定、最小权限和撤销机制。
4. **Copilot 本周更新显示多 Agent 工作台正在产品化。** GitHub 公布 Claude Fable 5.2、Gemini 4 Carbon、Agents Inbox、实验性模型对比、MCP connector 内联重新授权等变化，并预告 2027 年 2 月移除 local harness。[来源：GitHub，2026-11-16](https://github.blog/changelog/2026-11-16-github-copilot-weekly-releases-november-9/)。**影响判断：**模型切换、任务收件箱和连接器授权正成为编码 Agent 的标准工作流。**行动建议：**依赖 local harness 的团队先做迁移清单，并把 MCP 重新授权纳入失效演练。
