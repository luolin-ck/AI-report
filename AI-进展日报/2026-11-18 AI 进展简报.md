## 今日最值得关注

1. **GPT‑6.2 把“模型能力”推进到可交付的专业成品与交互设计。** OpenAI 11 月 17 日发布 GPT‑6.2 Astra 与 Sol；Astra 强调更好的文档、表格、幻灯片、代码、网页和 3D 设计，API 标准价为每百万 token 8 美元输入、0.40 美元缓存输入、40 美元输出，Sol 延续 2/0.10/10 美元。[来源：OpenAI，2026-11-17](https://openai.com/index/introducing-gpt-6-2-astra-sol/)。**影响判断：**设计到代码与专业文档 Agent 的竞争点会从“能生成”转向“少返工、能按模板交付”。**行动建议：**用自有模板、复杂前端和真实审批轮次做盲测，不直接接受厂商榜单。
2. **Firecrawl 把网页搜索与结构化商业数据合成 UltraSearch。** 11 月 17 日发布的 UltraSearch 可在结果中附带 2.5 亿以上人员职位、7,500 万以上公司融资和 15 万以上股票实时价格等数据片段。[来源：Firecrawl](https://www.firecrawl.dev/changelog/ultrasearch)。**影响判断：**RAG 采集正从“抓网页”扩展为“网页 + 专业数据提供商”的统一检索层。**行动建议：**重点验证来源可追溯、字段时效、同实体去重、许可边界与成本，而不是只看覆盖数字。
3. **GitHub Copilot Evals 把 skills、agents 和 MCP 工具纳入可重复回归测试。** 公测版允许创建真实任务、定义检查项、批准每次运行、定位失败，并比较自定义能力变更前后的结果；底层使用本地评测工具 Vally。[来源：GitHub，2026-11-17](https://github.blog/changelog/2026-11-17-github-copilot-evals-is-now-in-public-preview/)。**影响判断：**Agent 定制将从“装完能跑”转向“有基线、有回归、有证据”。**行动建议：**先挑 10—20 个高频任务建立固定验收，不要用一次成功 demo 代替评测。
4. **Copilot 浏览器操作进入 CLI、桌面应用、VS Code 与 JetBrains 公测。** 配合 Chrome 扩展，Copilot 可控制浏览器、实时调试网页、自动化测试和处理复杂网页任务，并提供权限级别设置。[来源：GitHub，2026-11-17](https://github.blog/changelog/2026-11-17-let-github-copilot-interact-with-your-browser/)。**影响判断：**编码 Agent 的“眼睛和手”从 DevTools/MCP 扩展到真实登录态浏览器。**行动建议：**先用隔离浏览器、测试账号和域名白名单验证，避免把个人会话直接交给 Agent。
5. **Figma 开始治理 MCP 客户端的组织级接入。** Organization 与 Enterprise 管理员可维护已批准 OAuth 应用白名单，覆盖 Cursor、Claude Code 等 MCP 客户端，并审核应用请求。[来源：Figma Release Notes，2026-11-17](https://www.figma.com/release-notes/)。**影响判断：**设计到代码落地的瓶颈不只在生成质量，还在连接器来源、授权和撤销。**行动建议：**把 Figma MCP 客户端列入组织应用清单，记录权限、负责人和下线流程。
6. **Microsoft MAI Code 2 押注“日常工程任务的价格性能”。** MAI Code 2 面向多文件实现、调试、仓库推理和 UI，Flash 面向解释、局部编辑与高频修复；官方明确它们尚未针对基础科学和超长周期 Agent 任务优化。[来源：Microsoft AI，2026-11-17](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)。**影响判断：**编码模型会进一步按任务时长与成本分层。**行动建议：**将例行修改与高风险架构任务分开路由，并把官方价格比较视为特定配置结果。
7. **GitHub Trending 的增量信号集中在技能框架、AI 办公、Agent UI 与自动研究。** 当日完整页面 15 个候选中，统一 AI 判据排序前五为 Superpowers、Univer、AG‑UI、PaperOrchestra、Claude‑BugHunter。[来源：GitHub Trending，11 月 18 日快照](https://github.com/trending?since=daily)。**影响判断：**“技能工程 + 人机界面 + 可复查研究产物”正在形成 Agent 基础设施主线。**行动建议：**优先试用能留下计划、测试、引用或审阅记录的项目。

## 分领域进展

### 设计生成

- **GPT‑6.2 Astra 把交互网页、3D 和模板化专业材料放到同一模型叙事里。** 官方展示从文字 brief 生成可交互浏览器体验、CAD/3D 设计、幻灯片模板匹配等能力，并称 Astra 在盲评中减少返工；这些仍是厂商及合作方评测，需要自测。[OpenAI 发布页](https://openai.com/index/introducing-gpt-6-2-astra-sol/)。适合 OpenDesign、Claude Design、Figma Make 类团队拿同一份复杂 brief 比较结构可编辑性、设计系统复用和代码质量。
- **Figma 11 月 17 日的新增重点是接入治理，不是新的生成模型。** OAuth allowlist 可控制哪些 MCP 客户端访问团队设计资产。[Figma Release Notes](https://www.figma.com/release-notes/)。这补齐了“设计 → Agent → 代码”链路的企业权限层；11 月 12 日的 3D/CSS/MCP 能力是最近 7 天基线，不重复包装成今日新品。
- **值得采用的评测框架：**对 prompt-to-design 工具同时检查视觉质量、组件语义、断点、token、可撤销编辑、设计系统约束、导出代码和真实浏览器 E2E，而不是只比较首屏截图。

### 数据采集 / RAG

- **Firecrawl UltraSearch 是本窗口最明确的新变化。** 它将通用搜索结果与 Alexandria 的人员、公司、股票等结构化片段合并，减少 Agent 再调用多个数据源的编排成本。[官方更新](https://www.firecrawl.dev/changelog/ultrasearch)。适合销售研究、公司尽调、投研和招聘，但必须核验数据来源、更新频率、可删除性与许可范围。
- **对 RAG 的迁移影响：**采集层需要从“URL + 正文”升级为“实体 + 字段 + 来源 + 时间戳 + 网页证据”。建议对同一查询保存网页出处、结构化字段提供商、抓取时间和冲突解决结果，避免把聚合片段当原始事实。
- **风险提示：**2.5 亿人员、7,500 万公司和实时行情均为 Firecrawl 官方口径；本期未取得独立覆盖审计，不把覆盖规模等同于准确率或合法可用范围。

### Agent 工作流

- **Copilot Evals：**让 skill、custom agent 和 MCP tool 接受重复任务、逐项检查及前后版本对比；每次运行须用户批准。[官方说明](https://github.blog/changelog/2026-11-17-github-copilot-evals-is-now-in-public-preview/)。适合建立技能准入和回归门禁。
- **浏览器操作：**Copilot Chrome 扩展与 CLI、应用、VS Code、JetBrains 配合，可调试网页、跑浏览器测试和完成网页任务。[官方说明](https://github.blog/changelog/2026-11-17-let-github-copilot-interact-with-your-browser/)。上线前应设计账号隔离、域名限制、下载控制和操作回放。
- **代码审查进入风险自适应。** Copilot code review 可按 PR 复杂度在 Lite/Balanced/Max 间选择，使用公开跨仓上下文并检测已知格式与 AI/ML 识别的秘密；Azure Repos 代码审查已 GA。[GitHub，2026-11-17](https://github.blog/changelog/2026-11-17-copilot-code-review-adaptive-effort-secret-detection-and-more/)。适合先在非阻断模式统计误报、漏报和采纳率。
- **验证工程成为规模化并行的前提。** Claude Code 团队公开其 E2E、属性测试、差分测试与失败升级方法，并称约 90% 代码由 Claude 编写和审阅；这是团队自述，应作为方法案例而非普遍生产率结论。[原文，2026-11-16](https://claude.dev/blog/how-the-claude-code-team-thinks-about-verification/)。

### 热门应用

- **GitHub Copilot Browser Use：值得试。** 适合前端调试、回归测试、表单与网页流程；真正价值是把“代码修改 → 浏览器验证”收进同一 Agent 会话。试用门槛是 Chrome 扩展与客户端开关，风险是登录态和跨站权限。
- **GitHub Copilot Evals：值得团队优先试。** 对技能、Agent 和 MCP 迭代频繁的团队，它比再装一个新模型更能降低回归风险；公测阶段应保留人工批准和本地日志。
- **Firecrawl UltraSearch：有明确垂直研究场景。** 对公司、人员和证券研究能减少多 API 编排；对普通网页问答未必需要升级，先比较命中率、引用质量与单次成本。

### Agent 验证栈：从“模型自评”到可重复任务、真实环境与独立证据

今天的 GPT‑6.2、Copilot Evals、浏览器操作、风险自适应代码审查、Claude Code 验证方法和 FrontierHarness Eval 指向同一结论：模型更强并不会自动带来可交付性，验证环境才决定团队能否安全放大并行度。建议建立四层验证栈：静态规则与秘密扫描；单元/属性/差分测试；真实浏览器或模拟器 E2E；与实现 Agent 分离的 rubric grader。每次记录模型、harness、skill/MCP 版本、通过率、成本、失败类别和人工接管，才能判断升级究竟减少了返工还是只提升了 demo 观感。
