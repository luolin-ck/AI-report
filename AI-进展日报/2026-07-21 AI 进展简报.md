## 分领域进展

### 设计生成

Figma Config 2026 的核心信号是把代码、动效和生成式插件放回设计画布。Code Layers 允许把 GitHub 或本地项目导入 Figma 画布，以代码图层的形式预览、调整并推回仓库；Figma Motion 则把时间线、Dev Mode 可检查动画和 CSS/JSON/React 导出放进协作流程。Google Stitch 继续强调从自然语言、线框、截图生成多屏 UI，可导出到 Figma，并输出语义 HTML/CSS 和 Tailwind。OpenDesign 的仓库页显示约 80.1k stars，定位是开源 Claude Design 替代品，强调本地优先桌面端、设计系统、插件、原型、仪表盘、PPT/PDF/视频导出和多 Agent 编码工具适配。

可行动判断：短期不要只比较“谁生成的首屏更漂亮”，而要比较是否能复用团队组件、是否能导出可维护代码、是否支持动效交付、是否有版本控制和审查路径。适合产品设计团队用 Figma Code Layers/Motion 做真实项目试点，独立开发者可用 Stitch/OpenDesign 快速探索原型。

### 数据采集/RAG

可行动判断：RAG 项目下一阶段的瓶颈不是向量库，而是数据进入系统前的监控、去噪、变更摘要和权限隔离。适合抓取竞品价格、政策页、API 文档、招聘页、开源项目 release notes；不适合无边界抓取用户隐私页或登录墙内容。

## 今天值得深入研究的 1 个主题

**Agent 安全边界：从沙箱到数据供应链。**

今天的两条安全线索分别来自编码 Agent 沙箱逃逸和 Hugging Face autonomous agent 入侵事件。它们共同说明：Agent 风险不只在模型回答，而在工具调用、文件系统、容器挂载、Docker socket、Git 命令、数据集解析和自动执行链路。建议深入研究三个问题：哪些资源绝不能暴露给 Agent 默认环境；如何为抓取、解析、执行、提交设置分级权限；如何在代码审查、日志、回滚和密钥轮换中形成闭环。

## 可忽略的噪音

1. 只用总 stars 排名冒充“今日增长”的榜单。今天的 GitHub 模块只采用 GitHub Trending `stars today` 公开口径，未拿到精确 API 增量时不写精确新增。
2. 单条 X/Twitter 截图、无法打开的转发热帖和无来源观看量。未能公开验证互动数据时，只能写“未获取到精确互动数据”。
3. 旧文章被社区重新翻出但标题像新发布的内容。例如 Replit Snapshot Engine 是 2025 年文章，今天只可作为“被重新讨论”的背景，不应当写成新功能发布。
4. 只展示一次性 UI demo、没有导出、组件复用、版本控制和权限模型的 AI 设计生成工具。它们可以看灵感，但不值得马上纳入生产流程。
