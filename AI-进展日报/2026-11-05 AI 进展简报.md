## 今天值得深入研究的 1 个主题

### 多 Agent 的真正瓶颈正在从“会不会写代码”转向“能不能被治理”

Pierre 收购、Linux 安全流水线和 GitHub 今日热榜中的 `spec-kit`、`superpowers`、`i-have-adhd` 指向同一条主线：当 Agent 可以并行写代码、扫描漏洞和生成补丁后，最稀缺的能力变成了**规格、隔离、证据、差异审阅、冲突合并、权限和人工门禁**。

值得做一个两周内部实验：选一个中等规模仓库，让 2–3 个编码 Agent 在独立工作树执行同一规格；记录冲突率、无效 diff、评审时间、回滚次数和真实合并成功率。实验必须保留四类证据：输入规格、每个 Agent 的工作树/权限、机器测试与动态复现、最终人工审阅决定。只有这些指标改善，才说明多 Agent 提升了交付能力，而不只是增加了 token 和分支数量。
