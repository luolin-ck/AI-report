## 今日最值得关注

1. **Google 发起的 A2A 协议迁入 Agentic AI Foundation，Agent 标准正在分层。** 来源：[Axios, 2026-08-17](https://www.axios.com/2026/08/17/a2a-agentic-ai-foundation-open-ai-standards)。影响判断：MCP 更偏“Agent 连接工具/数据”，A2A 更偏“Agent 之间通信”，两者不是替代关系。行动建议：做企业 Agent 平台时，把“工具接入 MCP”和“跨 Agent 调度 A2A”分开评估，不要把所有集成都塞进一个工具协议。

6. **Figma Make / Figma Agent 的近期更新仍是设计生成主线：可视编辑、代码回 canvas、Weave 工具、网页搜索。** 来源：[Figma release notes](https://www.figma.com/release-notes/)、[Config 2026 help](https://help.figma.com/hc/en-us/articles/39582753756695-What-s-new-from-Config-2026)。影响判断：AI 设计生成正在从“一次性生成页面”转向“可控编辑 + 设计系统变量 + 代码互转”。行动建议：产品团队可用它做探索和回流，不应直接把生成结果当最终设计系统。

## 分领域进展

### 设计生成

- **Figma Make 编辑面板仍是近期最重要的设计生成更新。** Figma 7 月 30 日发布 Make editing panel，强调可在 chat 旁边叠加审阅编辑、用 annotation 指向局部并要求 Agent 调整、在不同设备 frame 中检查响应式效果。它的价值不是“自动出图”，而是把 AI 设计生成变成可控的局部迭代流程。
- **代码回 canvas 的能力开始和设计变量绑定。** Figma 7 月 16 日更新显示，从 Make preview、Figma MCP server 或 Chrome extension 带回 canvas 的 code-backed screens 会尽量绑定文件内变量，并增加 auto layout。对设计到代码/代码到设计工作流来说，这比单纯截图还原更有价值。
- **Weave 工具进入 Figma Design 后，AI 视觉生成更像工具链而非 prompt 玩具。** 官方帮助文档显示 Weave tools 在 Professional/Organization/Enterprise 的 full seat 中 open beta，可用于背景替换、Logo 添加、比例调整等常见 AI 图像任务；beta 期间不消耗 AI credits。适合品牌素材批处理、营销图变体、产品图修图，不适合直接产出需要法务/版权确认的最终资产。
- **Claude Design 仍是“AI 做视觉工作”的重要参照，但本轮未发现 24-48 小时官方新版本。** 它的定位是通过 Claude 生成设计、原型、slide、one-pager 等视觉产物。今天更值得关注的是传播层面：设计创作者对 AI 广告的反弹，说明工具落地需要谨慎定位为“辅助表达和探索”。

### 数据采集 / RAG

- **Firecrawl `/search` 的 relevant excerpts 是近期最值得复盘的 RAG 采集更新。** 官方 changelog 称 7 月 22 日升级后会按 query 返回最相关的段落、列表和表格片段，并宣称在 SimpleQA 上达到 94.7%，同时比处理整页少用 10 倍 token。口径说明：这是 Firecrawl 官方 benchmark 主张，适合作为选型线索，仍需用自己的数据集复测。
- **Firecrawl AnyDoc + pdf-inspector 把 PDF/文档解析变成基础设施。** 8 月 6 日产品更新介绍了两个 Rust 库，用于把常见文档格式转为干净 Markdown；`pdf-inspector` 负责识别扫描版/文本型 PDF 并路由提取路径。适合企业知识库、招股书/合同/论文 ingestion，重点验证表格、脚注、扫描件 OCR 和引用定位。
- **WebMCP + headless agent 的方向值得跟踪。** Firecrawl 7 月文章提出：站点如果暴露面向 Agent 的工具描述，云端浏览器交互可以减少 Agent 猜 HTML 的 token 和失败率。短期可作为实验，不建议生产依赖未稳定标准。

### Agent 工作流

- **A2A 进入 Agentic AI Foundation 是今天最明确的 Agent 标准新闻。** 它把“独立 Agent 间通信、发现、认证”放到更专门的基金会语境中。对于企业团队，短期重点不是立刻改造，而是开始区分三层：MCP 连接工具，Skills 描述工作流，A2A 处理 Agent-to-Agent 协作。
- **Agent 权限和可审计执行成为新产品主线。** Product Hunt 上 DCP 将自己定位为本地权限 vault，重点是“Agent 申请、用户批准、本地签名、密钥不进上下文”。虽然它不是本周新发布，但在 Agent 处理钱包、API key、x402、远程 sidecar 的背景下，问题非常现实。
- **Agent 记忆仍在升温。** GitHub 今日热榜中的 `ai-memory` 针对 Claude Code、Codex 等 coding CLI 的跨工具交接：中途退出 Claude Code，再在同目录启动 Codex，不重新解释架构、失败尝试和开放问题。这类项目说明“任务连续性”正在变成 Agent 基建需求。

### 热门应用

- **MoneyPrinterTurbo：AI 短视频流水线继续吸引关注。** 它支持从主题/关键词生成脚本、匹配素材、字幕、BGM，并合成高清短视频，还支持 Agent、WebUI、API、CLI。适合做 Shorts/TikTok/视频号批量草稿，但需要人工把关事实、版权和平台重复内容风险。
- **Strix：AI 安全测试从 demo 进入 CI/CD 语境。** README 显示它可以像真实黑客一样动态运行代码、找漏洞并生成 PoC，且新增 GitHub Actions/CI/CD 集成提示。只适合授权范围内安全测试，不应对第三方目标运行。
- **llmfit：本地模型选择开始工具化。** 它会检测 RAM、CPU、GPU，并按质量、速度、硬件适配和上下文维度推荐可运行模型。适合准备本地 LLM、MLX/GGUF/Unsloth 模型部署的个人和小团队。

- **Prime Agent / RLM harness：** 近期继续被技术社区讨论。它的核心思想是让模型通过持久 Python REPL 管理上下文、调用 subagents、把 skills/memory 作为 durable harness state。值得研究，但应警惕“自我改进”带来的可审计性和回滚要求。

## 今天值得深入研究的 1 个主题
