## 今日最值得关注

1. **MCP Reference Servers v2.4.0 是安全升级，不是 Core 协议升级。** 官方一次修复 filesystem、git、fetch 三个参考服务器的六项安全问题，涉及路径逃逸、仓库配置命令执行与 SSRF；MCP Core 稳定版仍是 `2026-07-28`。[官方 release](https://github.com/modelcontextprotocol/servers/releases/tag/v2.4.0)｜**影响：**直接使用参考服务器的 Agent 权限边界可能被旧版本绕过。**行动：**显式 pin filesystem `2.3.0`、git/fetch `2026.11.11`，确认 Git 2.31+，并回归 symlink、私网 IPv6、robots 路径与响应体上限。
2. **Gemini Decisions API 把 Agent 的高频判断拆成低成本专用原语。** `gemini-decision-1` 单次最多处理 1,000 个独立判断，支持最高 256K tokens；官方称端到端延迟 150—250ms、每百万输入 tokens 0.10 美元且输出不计费。[Google 官方发布](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)｜**影响：**工具路由、权限预检、RAG 打分可能不再需要通用生成模型。**行动：**先以 100—1,000 条标注样本对比现有 LLM judge 的准确率、校准、延迟和误判成本。
3. **Adobe Firefly 从单点生成扩展到可复用创意流程与在品牌原型。** Firefly Graph 处于 beta，Builder 处于 private beta；后者支持自然语言生成并直接编辑交互式品牌原型、应用和网站。[Adobe 官方发布](https://news.adobe.com/news/2026/11/adobe-firefly-expands)｜**影响：**设计生成开始把品牌资产、可编辑画布、节点工作流和传统创作工具放到同一生产面。**行动：**用真实活动页同时测试设计 token、组件语义、交互可编辑性和导出代码 diff，而非只看首屏观感。
4. **Firecrawl 把论文抓取进一步产品化为 Agent 可直接消费的垂直索引。** 官方称 AI/ML Research Index 覆盖 300 万篇以上论文，可发现当天论文并读取全文。[Firecrawl 更新](https://www.firecrawl.dev/changelog/ai-ml-research-index)｜**影响：**研究雷达与自动综述可减少自建抓取解析管道。**行动：**先用已知论文集验证 DOI 去重、全文覆盖、元数据一致性和发现时延；300 万为官方自报，尚无独立覆盖率审计。
5. **Claude 把 AI 办公界面推进到白板、表格与受治理数据对象。** Whiteboards、Sheets 为 beta，Claude Data 已 GA；企业端 Data 将于 11 月 19 日默认开启，Sheets beta 官方限制约 10 万单元格且暂不支持 pivot tables、VBA、Power Query、DAX。[Anthropic 官方文章](https://claude.com/resources/articles/sheets-whiteboards-data)｜**影响：**竞争焦点从聊天体验转向协作对象、数据连接和企业默认权限。**行动：**管理员应在默认开关生效前复核连接器、共享边界，并用复杂工作簿做回归。
6. **Agent 会话正在成为独立的可迁移数据层。** Atuin 18.24+ 的 Threads 可搜索、同步、恢复和跨工具 fork Claude Code、Codex、Pi、Omp、OpenCode 会话，并提供端到端加密与 MCP 接口。[Atuin 官方博客](https://blog.atuin.sh/threads-agent-sessions/)｜**影响：**多 Agent 开发者可降低上下文丢失与工具锁定。**行动：**先在不含生产凭证的本地模式审计采集范围、恢复保真度与删除流程。
7. **Workspace MCP 的 OAuth Agent 标记进入强制执行期。** 从 11 月 11 日起，Gmail、Calendar、Chat 的 Workspace MCP server 会拒绝未标记为“AI-powered agent”的 OAuth client；非 Agent REST 应用不受影响。[Google Workspace 发布说明](https://developers.google.com/workspace/release-notes)｜**影响：**混用同一 OAuth client 的集成可能突然中断。**行动：**拆分 MCP 与普通 REST client，在测试租户复测同意页、scope 与错误码。该公告早于 7 天，仅因当前生效日纳入，不是今日新品。

## 分领域进展

### 设计生成

Adobe 的这轮变化比“再加一个生成模型”更值得看：Firefly Graph beta 把定制创意流程做成可重复节点图，Firefly Builder private beta 面向可直接编辑的 on-brand 原型、应用和网站，Firefly Design 则把 raster、vector、motion、3D、print 放到同一画布；Photoshop、Illustrator、Premiere、After Effects 的本地能力也通过 MCP 集成进入 Agent 工作流。[产品扩展](https://news.adobe.com/news/2026/11/adobe-firefly-expands)｜[补充发布](https://news.adobe.com/news/2026/11/adobe-powers-new-era-of-creativity)

成熟度必须拆开看：Graph 是 beta，Builder 是 private beta，不能统称全面 GA；官方也未披露用户量、生成成功率或设计到代码保真率。适合已有 Adobe 资产与品牌规范的团队试用，但生产验收仍应覆盖无障碍、组件语义和代码可维护性。Figma 方面未发现晚于昨日 Motion 的重要官方更新，本期不重复包装。

### 数据采集 / RAG

Firecrawl AI/ML Research Index 的价值在于把“抓取网页”上移成“给 Agent 一个垂直、可检索、可读全文的数据入口”。官方宣称覆盖 300 万篇以上论文、能发现当天发布内容，并可通过 Firecrawl 插件接入 ChatGPT、Claude 或其他 Agent harness。[官方更新](https://www.firecrawl.dev/changelog/ai-ml-research-index)

值得试的场景是研究雷达、技术尽调和自动综述；但 RAG 团队不应直接把官方规模当成质量证明。上线前至少核对 DOI/版本、重复稿、全文许可、引用溯源、召回率与更新 SLA。本项与昨日 Firecrawl 求职数据工具属于不同产品线，不是旧闻换名。

### Agent 工作流

- **决策层：** Gemini Decisions API 把 yes/no、choice、rubric 判断做成批量概率输出，适合工具路由、政策守门和上下文筛选；它不是通用推理模型，错误成本与概率校准仍需自有数据验证。[官方发布](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)｜[Vercel 支持记录](https://vercel.com/changelog)
- **会话层：** Atuin Threads 把跨 Agent 会话搜索、同步、恢复和 fork 做成 opt-in 的本地优先层；潜在收益是连续性，主要风险是会话中可能含凭证、代码和客户数据。[官方博客](https://blog.atuin.sh/threads-agent-sessions/)
- **身份层：** Workspace MCP 的 OAuth Agent 标记从“未来要求”变为当前强制执行；混用普通 REST 与 MCP 的应用应拆分 client，而不是只重试失败请求。[发布说明](https://developers.google.com/workspace/release-notes)

### MCP / Agent Skills 更新

#### 本次发现：Reference Servers v2.4.0（2026-11-11）

[官方 release](https://github.com/modelcontextprotocol/servers/releases/tag/v2.4.0) 显示，v2.4.0 修复 filesystem、git、fetch 三个参考服务器共六项安全问题。它**不是 MCP Core 协议版本升级**；Core 稳定基线仍为 `2026-07-28`。

- **filesystem `2.3.0`：**强化 symlink/TOCTOU 路径约束、`move_file` 源路径校验，拒绝 FIFO、socket、device 等特殊文件，并支持按目录只读。官方仍注明 Windows junction 是未完全覆盖边界。
- **mcp-server-git `2026.11.11`：**阻止仓库 `.git/config` 通过 `core.fsmonitor`、`diff.external`、hook、filter、merge、signing 等配置触发命令执行；最低要求 Git 2.31+。

- **迁移陷阱：**npm 的 semver 排序可能让 `2.3.0` 排在旧的日期版本之后；filesystem 应显式安装 `@modelcontextprotocol/server-filesystem@2.3.0`，不要依赖模糊版本选择。

适合谁先升级：在本地或 CI 中直接运行官方 filesystem/git/fetch server 的团队、Agent 平台与安全团队。建议完成版本盘点后，回归 symlink/特殊文件、恶意 `.git/config`、私网 IPv6、robots 路径和超大响应体。

## 今天值得深入研究的 1 个主题

### 把 Agent 拆成“生成、决策、执行、验证”四层

Gemini Decisions API 的意义不是又多一个模型，而是给 Agent 架构增加了可批量、可计量的“决策层”。一个可验证的试验路径是：

1. 选取工具路由、权限预检或 RAG 文档筛选中的一个窄任务；
2. 准备 100—1,000 条带标签样本与明确错误成本；
3. 对比通用模型、规则系统和专用决策 API 的准确率、概率校准、P95 延迟与单次成本；
4. 决策通过后再进入浏览器/MCP 等执行层，执行前后分别做权限与结果验证；
5. 为高风险动作保留人工确认，并记录可回放证据。

这套分层同时呼应 United Airlines 对交易 Agent 的限制、MCP v2.4.0 的权限边界修复，以及玛雅遗址案例暴露的 novelty 验证缺口。
